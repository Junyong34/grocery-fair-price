# 01. 용어(상품·카테고리)와 ADR 0005 "카탈로그 원본은 DB"

Status: resolved

## 목적

이후 티켓이 쓸 말과 결정을 먼저 고정한다. `domain-modeling` 스킬로 한다.

## 할 일

- [x] GLOSSARY **상품**: "하나의 품종에 속한다"를 고친다. 가공식품 상품은 품종 없이 카테고리 아래 바로 놓이고 그 자체로 화면 한 페이지다. 신선식품 상품(브랜드 계란·쌀 등)은 지금처럼 품종에 묶인다
- [x] GLOSSARY **카테고리**: 가공식품 계열 카테고리를 넣을 자리를 정의에 반영한다(목록은 05)
- [x] 화면 표기: 가공식품을 화면에서 무엇이라 부를지 (예: "상품", "가공식품"). 기존 "식재료" 규칙과 겹치지 않게
- [x] ADR 0005: 카탈로그 원본을 코드에서 DB 표로 옮긴다. 근거(수천 개, AI 제안·일괄 승인), 조건(Pro 일일 백업, 로컬 전용 어드민, 변경 기록 표), 대체하는 결정(catalog-evolution 02·03·05)
- [x] [catalog-evolution/spec.md](../../catalog-evolution/spec.md) 맨 위에 대체 안내 한 줄

## 완료 기준

- GLOSSARY와 ADR 0005가 커밋되고, 다른 티켓이 그 용어로 쓰인다.

## Answer

2026-11-09, 사용자와 문답으로 정했다.

- **상품**: 언제나 하나의 품목에 속하고, 그 가격이 품종의 시세로 쓰일 때만 품종에도 속한다. 신라면 120g×5는 품목 라면, 품종 없음. 품종이 없는 상품은 판정하지 않고 판매처·업태별 판매가를 보여 준다. "라면"을 품종으로 두는 안은 버렸다. 품종의 뜻("하나의 평소가를 기대")과 어긋나기 때문이다.
- **품목**: 품종과 상품의 상위 분류(라면, 우유 포함).
- **카테고리**: 신선식품과 가공식품을 함께 담는다. 출처 분류는 대응시켜 쓰고 화면 분류로 그대로 쓰지 않는다.
- **별칭·미등록 검색어**: 상품까지 가리킨다.
- **화면 표기**: 상품도 식재료와 가르지 않고 단어 없이 쓴다. 구분은 카테고리 이름으로 드러낸다.
- **ADR 0005**: [카탈로그 원본은 DB](../../../grocery-price/docs/adr/0005-catalog-source-is-db.md). 백업은 Pro 일일 백업 대신 **승인마다 카탈로그 표를 저장소에 JSON으로 내보내 커밋**한다(사용자가 Pro 전환을 "데이터가 찰 때"로 미룸, 2026-11-09).
