# 07. 로컬 카탈로그 어드민 `/admin/catalog`

Status: needs-triage
Type: task
Blocked by: 04

## 목적

카탈로그를 사람이 보고 고치는 화면. `pnpm dev`에서만 열리고, 운영 DB에 소유자 접속으로 쓴다. 기존 `/admin`(인쇄물)과 같은 방식으로 운영 빌드에서 빠진다.

## 화면

- **제안 목록**: 출처·원천 이름·제안 내용·근거. 한 건씩 또는 여러 건 골라 승인·반려. 승인 전에 "바뀔 매핑 수·다시 매핑될 관측값 수·숨겨질 품종"을 보여 준다 (dry-run)
- **pending 목록**: 제안이 없는 것. 직접 연결·제외·보류
- **카탈로그 탐색**: 카테고리 → 품목 → 품종 → 규격, 상품. 이름 고치기, 별칭, 숨김, 기본 규격 바꾸기
- **묶기**: 품종 둘을 하나로, 상품 둘을 하나로(`product.merged_into`). slug는 남은 쪽 것을 쓰고 옛 slug 처리(리다이렉트 여부)는 이 티켓에서 정한다
- **변경 기록**: `catalog_change` 최근 목록
