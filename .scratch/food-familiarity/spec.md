# 인쇄물 품종 친숙도 5등급

인쇄물 칸에 제철 품종을 다 넣지 못할 때, 일반 사용자가 자주 사 먹고 좋아하는 품종부터 넣는다. 지금은 대표 달이 친숙도보다 먼저라, 대표 달인 낯선 품종(매생이 등)이 제철이지만 대표 달이 아닌 흔한 품종(시금치 등)을 밀어낸다.

## 결정

1. 정렬: `친숙도 → 대표 달 → core → 제철 짧은 순 → 이름순` (`packages/seasonal/src/print/foods.ts` `byFocus`). 품종을 고르는 모든 인쇄물 종류에 적용한다. 이유식 두 종류는 해당 없음.
2. 친숙도 5등급. 개수가 아니라 정의로 나눈다. 값은 `packages/seasonal/src/data/food-familiarity.ts` 한 곳에서 전역으로 관리하고 어드민에서 바꾸지 않는다. 근거는 편집 판단이다.
   - 1: 거의 매주 장바구니에 들어가는 품종
   - 2: 한 철에 한 번 이상은 꼭 사 먹는 품종
   - 3: 알고 있고 가끔 사는 품종
   - 4: 이름은 알지만 일부러 찾아야 하는 품종
   - 5: 이름을 들어도 잘 모르는 품종
3. 최적 달(`bestMonth`)은 1·2등급 모두 손으로 지정한다(대표 달 안에서, 달마다 고르게). 나머지는 지금처럼 대표 달이 시작하는 달. 한 품종이 한 해에 한 번만 나오는 규칙(연간 한 장·표지·막대표)은 그대로 둔다. 달 단위 인쇄물은 지금도 제철인 달마다 나온다.
5. (2026-11-11 추가) 카테고리를 고른 인쇄물(과일·해산물 연간 달력, 카테고리를 고른 월별 포스터·체크 목록)은 `1·2등급 → 대표 달 → 친숙도 → (이하 1과 같음)`로 정렬한다(`byCategoryMonth`). 한 카테고리만 모으면 칸이 적어, 대표 달이 아닌 3등급(5월 애플망고)이 대표 달인 4등급(5월 카라향)을 밀어냈다. 같은 날 사용자 판단으로 샤인머스캣을 2등급(최적 달 9월, 포도는 8월로 옮김)으로 올리고, 카라향을 4등급에서 3등급으로 내렸다. 대저토마토는 토마토와 달리 `과일`로 분류한다(사용자: "대저토마토 채소지만 과일로 분류해줘").
4. 완료 순서: 아래 초안 검토 → 공개 에디션 9개(이유식 제외)의 칸별 전후 비교표 승인 → 코드 반영 → 어드민 "PDF 생성"으로 PDF·썸네일·build.json 재생성. R2 재공개는 따로.

## 초안 (검토용)

등급별 수: 1등급 25, 2등급 30, 3등급 62, 4등급 81, 5등급 42. "지금"은 바꾸기 전 3등급 값(1 흔함, 2 기본, 3 드묾). 검토 뒤 감성돔·농어·숭어·민어는 회 추천 기준(친숙도 3 이하)을 지키려고 3등급, 딸기는 1월 칸에서 빠지지 않게 1등급으로 올렸다. 반영한 값은 food-familiarity.ts가 기준이다.
