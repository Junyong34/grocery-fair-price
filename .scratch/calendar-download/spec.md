# 제철 인쇄물 내려받기

Status: ready-for-agent (04 와이어프레임 확정 2026-10-29: 1-a · 2-C · 3-B · 5-a)
Phase: MVP 이후.
작성일: 2026-10-29 (grill-with-docs 세션)

## 목표

운영자가 어드민에서 만든 **에디션** PDF를 사용자가 제철달력 화면에서 골라 내려받는다. 나중에 내려받기 전에 광고를 보게 할 수 있도록, 처음부터 링크가 우리 주소를 거치게 만든다.

이 스펙은 사용자 쪽과 "게시"(업로드)만 다룬다. 에디션을 구성하고 PDF를 뽑는 어드민은 `.scratch/calendar-print/spec.md`가 기준이다. 그 스펙 302줄의 "다운로드 폴더"(`public/downloads/`, Supabase Storage 안)는 이 스펙과 ADR 0003으로 대체한다.

## 용어

`grocery-price/GLOSSARY.md` "인쇄물" 절: **인쇄물 종류**(4가지), **에디션**(운영자가 구성해 내놓는 단위), **용지**. "타입"·"템플릿"·"버전"이라 쓰지 않는다.

## 처음 내놓을 구성

운영자가 만드는 에디션 15개: 월간 달력 4, 연간 달력 한 장 3, 계절 제철 포스터 4, 월별 제철 포스터 4. 숫자는 운영 판단이고 코드는 개수를 가정하지 않는다.

## 결정

| 주제 | 결정 | 이유 |
|---|---|---|
| 저장소 | 비공개 Cloudflare R2 버킷. 커스텀 도메인 없음 | ADR 0003. 월간 달력 A4 7.45MB(실측), Supabase 무료 쿼터는 가격 DB와 나눠 써 여유가 없다. R2 egress 무료 |
| 전달 | Route Handler가 R2 presigned URL(수명 60초)을 만들어 302 | 링크가 퍼져도 곧 무효. 광고 검사·다운로드 집계·저장소 교체의 자리 |
| 색인 | 내려받기 주소 응답 `X-Robots-Tag: noindex`(Disallow는 쓰지 않는다: 이 저장소는 noindex로만 막는다). 목록·에디션 페이지는 색인 | 검색 유입이 반드시 우리 화면을 거친다 |
| rate limit | 처음엔 없음 | R2 읽기 요청 무료 한도가 넉넉하다. 악용이 보이면 Route Handler에 더한다 |
| 용지 | 생성은 A4·A3 둘 다, **공개(업로드)는 A4만**. 사용자 화면에 용지 고르기 없음 | A3 수요를 모른다. "A3도 원해요" 버튼 클릭 수(GA)로 판단한다 |
| 에디션 목록 | `public/downloads/manifest.json`을 git에 커밋, 배포로 반영 | 1년에 몇 번 바뀐다. 목록이 정적이라 빠르고 색인된다 |
| 연도 있는 에디션 | 해마다 **새 에디션**. 운영자가 11월에 다음 해 에디션을 게시하고(화면은 날짜로 거르지 않는다, 줄 안에서 새 연도가 앞), 지난해 것은 12월까지 둔 뒤 1월에 내린다 | 같은 링크의 내용이 몰래 바뀌지 않는다 |
| 월간 달력 파일 | 1년치(표지 + 12달) 한 파일만 | 한 달만은 인쇄 대화상자의 쪽 범위로. 한 장 수요는 월별 포스터가 받는다 |
| 미리보기 | PDF 생성 때 같은 인쇄 페이지의 **1쪽을 WebP로 찍은 썸네일**(월간 달력은 표지 + 1월 쪽 두 장). `public/downloads/<id>/`에 두고 git에 커밋한다(PDF만 gitignore). 카드에 설명·연도·방향·쪽 수 | 2026-10-29 와이어프레임 검토에서 바꿈: 구성이 같은 에디션끼리 와이어프레임으로는 구분되지 않는다. 썸네일은 작아(수십 KB) 저장소·CDN에 둬도 되고, 목록이 R2를 거치지 않는다 |
| 에디션 상세 | `/seasonal/downloads/[edition]`. 목록에서 누르면 바텀시트(intercepting route), 직접 열면 전체 페이지 | 품종 상세(`@sheet/(.)foods/[food]`)와 같은 방식. 공유 링크·색인 |
| 내려간 에디션 | 그 주소는 "이 인쇄물은 내려갔어요" + 같은 종류 최신 에디션 카드 | 공유된 옛 링크가 404로 끝나지 않는다. 다른 해 달력으로 몰래 넘기지 않는다 |
| 입구 | 2a·2b에 고정 카드 "제철 달력 · 포스터 PDF 받기" 하나 + 기존 설정 패널 링크 | 시기별 카드는 다운로드 수 데이터가 생긴 뒤에 |
| 광고 | 지금은 없음. 흐름에 "광고 자리" 단계만 비워 둔다 | 나중에 Route Handler가 광고 완료를 확인하고 발급한다 |
| 측정 | GA4를 새로 연결. 이벤트: 내려받기(에디션 id), A3 요청(에디션 id) | 호스팅(Vercel 여부)이 미정이라 Vercel Analytics가 아니라 GA |

## 사용자 흐름

```
2a 이달 / 2b 월별 ── 카드 "제철 달력 · 포스터 PDF 받기" ─┐
설정 패널 링크 ─────────────────────────────────────────┤
                                                        ▼
                        /seasonal/downloads (목록: 달력 / 포스터 묶음, 에디션 카드)
                                                        │ 카드 탭
                                                        ▼
                        에디션 상세 (바텀시트, 직접 열면 페이지)
                        썸네일 · 설명 · 연도 · 방향 · 쪽 수 · 크기
                        [PDF 내려받기 (A4)]   [A3도 원해요]
                                                        │
                                       [광고 자리 — 지금은 건너뜀]
                                                        ▼
                        GET /seasonal/downloads/[edition]/a4 → 302 → R2 presigned
                                                        │
                                                        ▼
                        완료 상태: "내려받았어요" · 링크 복사 · 공유 시트(navigator.share)
                        (휴대폰 사용자는 PC로 보내 인쇄하는 경우가 많다)

/seasonal/downloads/[내려간 edition] → 안내 + 같은 종류 최신 에디션 카드
```

와이어프레임(04)에서 목록과 상세는 2~3안을 나란히 비교한다. 1280 폭은 디테일 단계에서.

## 운영자 흐름

1. 어드민에서 구성 → 저장 → PDF 생성(A4·A3, 로컬 `public/downloads/`, gitignore).
2. 상태를 `published`로 바꾸고 **게시**: A4 PDF를 R2에 올리고(쓰기 키는 로컬 `.env`), `manifest.json`을 갱신. 설명이 비면 게시를 막는다.
3. 내릴 때는 상태를 바꿔 manifest의 내려간 목록으로 옮긴다. R2 파일은 지운다(새 링크는 Route Handler가 막는다).
4. 사양 JSON과 `manifest.json`을 한 커밋으로 올리고 배포.

## 데이터 모양 (manifest)

지금 `ManifestEntry`(`packages/seasonal/src/print/edition.ts`)에서 바뀌는 것:

- `files`는 공개 용지만 담는다(`PUBLISHED_PAPERS = ["A4"]` 상수 하나). 경로는 R2 객체 키가 아니라 우리 주소다.
- 미리보기용 값: 썸네일 경로(1~2장, 가로세로 크기 포함), `year`(있으면), 방향, 쪽 수.
- `withdrawn: { id, kind, title }[]`: 내려간 에디션. 안내 화면이 쓴다.
- `description`은 게시된 에디션에서 비어 있지 않다.

## 계층

- R2 서명(읽기)은 서버 전용 모듈, 업로드(쓰기)는 어드민 서버 코드(`features/admin-print/server/`)에만 둔다.

## 범위 밖

- 광고 게이트 구현. FAQ·문의 페이지(A3 문의 메일은 그때).
- A3 공개, 월별 분할 파일.
- PDF 크기 줄이기는 09에서 조사만 한다.

- 개인정보 처리방침은 10에서 만든다. 쿠키 동의 배너는 넣지 않는다.
