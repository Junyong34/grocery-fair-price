## 목적

다운로드 수(에디션별)와 A3 수요를 GA4로 본다. 시기별 입구 카드, A3 공개, 광고 판단의 근거.

## 할 일

- [ ] GA4 속성 만들기(운영자), 측정 ID 환경변수. 프로젝트에 분석 도구가 아직 없다.
- [ ] Next 16.4에서 넣는 방법 확인(`@next/third-parties` 등, 문서 먼저). 개발 서버에서는 보내지 않는다.
- [ ] 이벤트: `print_download { edition_id, kind, paper }`, `print_a3_request { edition_id, kind }`. A3 버튼은 누르면 "알려 주셔서 고마워요" 상태로 바뀌고 같은 기기에서 다시 세지 않는다(`deviceStore`, 키 `seasonal:a3-requests`).
- [ ] 개인정보 처리방침·쿠키 고지 필요 여부 확인, 필요하면 별도 티켓.
- [ ] `.scratch/seo/spec.md`의 "GA4는 넣지 않는다"와 로드맵 P9에 이 결정을 적는다.
