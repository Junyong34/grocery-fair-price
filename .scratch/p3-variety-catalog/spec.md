# P3. 표현 가능 값 카탈로그 — 품종 목록 중심 작업 분해

로드맵 ② 판정 설계의 품종 목록 부분이다(이전 번호 P3). **MVP 품종 목록**을 데이터가 실제로 있는 품종 기준으로 정하고, 점포 데이터가 없는 품종에 무엇을 보여 줄지 정한다. 산출물은 `grocery-price/docs/30-data/variety-list.md`.

이 폴더는 그중 품종 목록과 공백 대응을 먼저 다룬다. 표시 항목 판정표(product-concept 4장)는 P2가 끝난 뒤 별도 이슈로 추가한다.
