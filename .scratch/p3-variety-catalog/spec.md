# P3. 표현 가능 값 카탈로그 — 품종 목록 중심 작업 분해

로드맵 P3의 목표: 각 출처로 무엇을 보여줄 수 있고 무엇을 못 보여주는지 확정하고, **MVP 품종 목록**을 데이터가 실제로 있는 품종 기준으로 정한다. 산출물은 `grocery-price/docs/30-data/display-catalog.md`.
