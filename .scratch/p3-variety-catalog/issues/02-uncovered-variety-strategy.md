# 02. 목록 밖 품종의 수집 방안

Status: ready-for-human
Type: grilling
Blocked by: 01

## 목적

공공 출처에 시세가 없는 품종(커버 상태 "없음")을 나중에 어떻게 채울지 방향을 정한다. 지금 구현하는 것이 아니라, 데이터 모델과 화면이 이 경우를 받아들일 수 있게 하기 위한 결정이다.

## 검토할 선택지

| 선택지 | 내용 | 관련 문서 |
|---|---|---|
| 사용자 제보 | 제보 가격만으로 판정. 표본이 적어 신뢰도가 낮음 | domain-model.md (제보, 이상 제보) |
| 공공 파일데이터 | 참가격 XLS 등 과거 파일 | api-spec.md 4장 |
| 다른 공공 API | 지자체 물가조사(15109061, 2022년에서 멈춤), 서울 OA-1170 등 | public-data-survey.md 보조 소스, gov-price-sites.md |
| 온라인몰 제휴·공식 API | 확장 단계 E1 | roadmap.md E1, ADR 0001 |
| 지원하지 않음 | "시세 정보 없음"으로 표시하고 미등록 검색어로만 기록 | GLOSSARY.md 미등록 검색어 |

## 결정할 것

- [ ] 커버 상태가 "없음"인 품종을 MVP 목록에 넣을지, 목록 밖으로 둘지
- [ ] 목록 밖 검색어를 어떻게 다룰지 (**미등록 검색어** 기록 → 다음 품종 추가 우선순위)
- [ ] 제보만 있는 품종의 판정 표시 규칙의 방향 (세부 계산식은 P5)
- [ ] 선택지별로 필요한 데이터 모델 요소가 있으면 `p4-canonical-model/01`에 전달할 요구사항으로 정리 (예: 출처 유형에 "제보" 포함)
- [ ] ADR 0001(크롤링 안 함)을 건드리는 선택지는 충돌을 명시

## 완료 기준

- 품종 커버 상태별 대응 방침이 `## Answer`에 표로 정리되어 있다.
- 결정이 되돌리기 어렵거나 의외라면 ADR로 남긴다.
