# 01. 품종 리스트업

Status: resolved
Type: grilling
Blocked by: p2-data-source-spec/13

## 목적

서비스가 판정할 **품종**의 목록을 만든다. 고기, 채소, 과일, 수산, 계란·유제품, 라면·가공식품, 양념 등 장보기에서 쓰는 식자재를 카테고리별로 나열하고, 각 품종이 어느 출처의 어느 코드로 시세를 받는지 연결한다.

초안은 에이전트가 p2/13 결과로 만들고, 사용자와 함께 범위를 정한다.

## 에이전트가 할 일

- [x] 카테고리별 품종 후보 표 초안 (카테고리, 품목, 품종, 규격, 기준 단위, 출처와 코드, 대응 제철 품종 id)
- [x] 각 품종에 **커버 상태** 표시
  - 충분: 매일 시세 (KAMIS, 축평원)
  - 부분: 격주·점포 한정 (참가격만)
  - 점포 데이터: 참가격 상품이 있어 점포·업태별 판매가가 나오는지 (배추·당근처럼 시세만 있는 품종 구분)
  - 없음: 어느 공공 출처에도 없음
- [x] 한 품종에 출처가 여럿이면 우선순위 후보 (예: 삼겹살 KAMIS `500-4304-27` vs 축평원 `4304`/`27`)

## 정해진 것 (2026-10-19)

- **가격 품종 ID는 제철 패키지(`packages/seasonal`)의 품종 ID와 별도 체계로 둔다.** 두 체계는 매핑표로 잇는다 (pipeline.md 3-1 `variety_seasonal_map`). 목록 초안에 대응하는 제철 품종 id 열을 함께 둔다.
- 참가격 상품은 소분류 단위로 품종에 묶고, 맞지 않는 상품만 예외로 고친다 (`search-first-view` 결정 8).
- 식품만 다룬다. 참가격 생활용품은 제외한다.

## 함께 정할 것 (도메인 모델이 아직 정하지 않은 질문)

1. **가공식품의 품종 단위**: 글로서리에서 품종은 "사용자가 하나의 평소가를 기대하는 식재료"다. 라면은 "라면" 전체인가, "신라면 봉지"처럼 상품 수준인가? 참가격의 데이터는 상품 단위(604개)다.
   - 결과에 따라 GLOSSARY.md의 **품종**·**상품** 정의를 보강해야 한다 (`/domain-modeling`)
2. **MVP 범위**: 처음부터 가공식품을 포함할지, 신선식품(KAMIS + 축평원)만으로 시작할지
3. 기준 단위가 애매한 품종 (예: 라면은 1봉? 100g?)

## Answer (2026-10-26)

산출물: [variety-list.md](../../../grocery-price/docs/30-data/variety-list.md). 품종 133개 (충분 + 점포 32, 충분 96, 부분 5), 제철 id가 이어진 품종 66개. 용어집의 **품종**(원산지가 다르면 다른 품종)·**규격**(등급·크기·보관 상태) 정의를 고쳤다.

1. **가공식품의 품종 단위**: 이번에는 정하지 않는다. MVP가 가공식품을 판정하지 않으므로 참가격 가공식품 386개는 수집만 하고 품종에 잇지 않는다(`ignored`). 가공식품을 넣을 때 다시 연다.
2. **MVP 범위**: 신선식품만. 우유·계란은 매일 시세가 있어 넣는다. 실제 소매 데이터가 오는 신선 품목은 다 넣고, 화면에 먼저 보일 것은 ③에서 정한다.
3. **기준 단위**: 장 볼 때 생각하는 단위. 개수로 사는 것 1개, 무게로 사는 채소·고기·수산 100g, 쌀 1kg, 계란 30구, 우유 1L. 개수↔무게 환산이 필요한 것(고등어 1손, 참가격 갈치 100g)은 환산 기준이 생길 때까지 기준 단위 가격을 비운다.

품종을 가르는 규칙 (grilling에서 정함):

- **사람이 하나의 식재료로 인식하면 한 품종.** 가격 차이 숫자로 자동으로 가르지 않는다 (10% 기준안은 버림). 사과 홍로·시나노골드는 사과 하나(상품끼리 1% 차이), 포도 캠벨얼리·거봉·샤인머스켓은 따로.
- 원산지는 품종을 가르고, 보관 상태와 크기는 규격. 등급도 규격이고 기본은 상품, 축산은 1+등급.
- 축산의 대표 출처는 pipeline 6-1(두 출처에 다 있으면 축평원).
- 애매했던 10건은 초안대로: 상추 적·청 한 품종, 오이 세 계통 한 품종, 대추방울토마토 따로, 감귤 노지·시설 한 품종, 명태 냉동가공 따로, 마른멸치 크기는 규격, 마른김·구운김 따로, 한우 불고기 넣음, 계란 30구, 한우 기본 1+등급.

로컬 샘플 시드의 `sagwa-hongro`(사과(홍로))를 `sagwa`(사과)로 고쳤다.
