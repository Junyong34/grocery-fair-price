- 현재 코드와 배포 응답을 구분하고, 원안의 수치마다 확인/반례/미확인으로 판정한다. 운영 수정은 하지 않는다.

## Answer

2026-11-04 서울15:12~15:16 공개 GET 표본 조사 완료. [공개 운영 응답 기준선](../research/public-baseline.md)에 URL·시각·요청 방법·상태·content-type·메타·링크·측정 한계를 기록했다.

- 확인: robots Allow /, sitemap408(가격127·제철품종240). 실제 검색엔진 색인 수는 미확인.
- 확인: 기본 OG와 실제 가지 제철 OG 쿼리 모두500·0바이트. 전체408개 실패·원인은 미확인.
- 확인: 없는 가격 slug는200 + noindex + Next404 표식. Suspense 밖 검증으로 고칠 수 있는지는 미확인.
- 확인: 다운로드2026년2종과 월간 상세 제목의 달력 반복, PDF 링크 존재. 파일 전달·인쇄 품질은 미검사.
- 확인: 가지 제철 상세→품종별 가격 링크 없음. 공통 셸 영역 간 링크는 있으므로 모든 링크0 주장은 범위를 좁힌다.
- 확인: 11월 회 본문 자바리·붉바리2종. 다른 종을 추가할 식품 근거는 별도 판단.
- 한계: 가격1종 캐시HIT 두 회 TTFB59/47ms와 총전송2.575/0.580s를 구분. cold·35/127개2초초과·전체성능·DB리전·오류원인은 확정하지 않음.

로컬 SEO 문구와 배포 차이는 있으나 배포SHA는 미확인이다. 남은 비공개 관측은 [운영 로그와 검색·분석 관측 공백 확보](02-private-observations.md), 성능 판단은 [리전과 제철 화면 성능의 투자 기준](08-performance.md)으로 넘긴다.

Branch pointer: `research/jangbol-public-baseline`, 조사 커밋 `8f75db1`, 격리 worktree `/tmp/jangbol-public-baseline-worktree`. 조사 파일만 로컬 커밋했으며 제품main에는 합치지 않았다. 원격 push는 자동 승인 검토가 거절했다. 사유: origin 소유권/신뢰성과 전송 이력 범위 미확인, 로컬 지도 작성 승인만으로 외부 전송 미승인. 재시도하지 않았으며 로컬 파일로 조사 완료 요건을 충족한다. 원격 보존이 필요하면 사용자의 별도 승인이 필요하다.
