## Question

가격 첫 요청과 제철 탐색의 어느 병목을 먼저 줄일 것이며, 어떤 측정 결과에서 리전·렌더링·캐시 정책을 바꿀 것인가?

- 함수 iad1과 DB 리전은 확인 전 가설이다. 사용자 위치·DB 왕복·쿼리·콜드 스타트·캐시를 구분해 icn1 고정이 유리한지 검증할 최소 측정을 정한다.
- 35/127개 2초 초과, 782 img·1.6MB HTML은 측정 조건과 재현 시각을 확인한다. 대표 URL의 첫/반복 요청과 기기 조건·바이트 기준을 맞춘다.
- 375/1280에서 초기 HTML·이미지·스크립트와 탐색 가능성을 비교할 예산을 정한다. 화면 밖 렌더 지연이 내부 링크·색인·접근성에 주는 영향도 정한다.
- immutable은 URL 버전/해시가 실제로 바뀌는 경우에만 후보로 둔다. 같은 SVG URL 덮어쓰기 상태에서 장기 캐시를 확정하지 않는다.

완료 산출물: 측정 프로토콜, 목표/회귀 기준, 우선할 변경과 하지 않을 변경, 기대 효과를 반증할 조건.
