# PDF 유입을 가격 확인으로 연결하기 — 결정 지도

Label: wayfinder:map
만든 날: 2026-11-04

## Destination

무료 제철 PDF로 방문자를 모으고 제철 탐색에서 가격 확인으로 이어지게 하는, 향후 2개월의 실행 명세를 확정한다.
각 실행 항목의 근거(THINK)·의존 관계·실패 판정 기준·선행 지표·담당·검증 방법·순서를 정하고, 실행 전에 필요한 결정이 남지 않으면 이 지도를 마친다. 최종 명세는 이 폴더의 `spec.md`로 인계한다.

## Notes

- 사용자가 2026-11-04 확정한 목적지와 자원: 개발자 1명, 운영자 참여 주 2시간. 개발자의 주당 작업 시간은 아직 정하지 않았으므로 전일 투입으로 계산하지 않는다.
- **계획 지도다.** 제품 구현, main push, 운영 설정 변경, PDF 발행, 외부 커뮤니티 게시까지 실행하는 지도가 아니다. 접근 확인과 읽기 전용 조사는 결정을 위한 증거 수집으로 허용한다.
- 입력 19개와 기존 주장의 출처·대응 위치는 [원안과 검증 출발점](input.md)에 보존한다. 원안의 Phase와 점수는 제안이며 확정 순서가 아니다. 페이지 수·장애·리전·검색수요는 운영 실측 전까지 가설이다.
- 색인·노출은 진단 지표이며 서비스 사용의 대체 지표가 아니다. PDF 클릭, 실제 파일 응답, 가격 상세 도달도 서로 구분한다. 성공 지표의 분모·기간·관측 한계는 결정 티켓에서 확정한다.
- 제철의 품종과 가격의 품종은 같은 이름이어도 범위·원산지·규격이 다를 수 있다. 링크 대응은 이름이나 slug 일치만으로 정하지 않는다. 용어는 [가격 용어집](../../grocery-price/GLOSSARY.md)을 따른다.
- 매 세션 `wayfinder`, `grilling`, `domain-modeling`과 [로컬 이슈 규칙](../../docs/agents/issue-tracker.md)을 읽는다. research에는 `research`, prototype에는 `prototype` 스킬을 적용한다. Next 관련 판단은 설치된 Next 문서와 [렌더링 규칙](../../apps/web/docs/nextjs-16-patterns.md)을 먼저 읽는다.
- 티켓 메타데이터는 `Parent`, `Label`, `Type`, `Mode`, `Status`, `Assignee`, `Blocked by`로 기록한다. `Status: open`이며 미할당이고 모든 선행 티켓이 resolved인 자식 중 번호가 가장 작은 것이 다음 frontier다. 의존 관계의 숫자는 이 폴더 안에서만 식별자로 사용한다. 사람에게는 제목으로 부른다.
- 시작 전에 `Status: claimed`와 `Assignee`를 저장한다. 해결 시 `## Answer`에 증거·결정·미확인 사항을 기록하고 resolved로 바꾼 뒤 이 지도의 Decisions so far에 제목 링크와 한 줄만 추가한다. 지도 작성 세션에는 사람이 결정할 티켓을 닫지 않는다.
- 기존 SEO·PDF·가격 화면 이슈를 복제 구현하지 않는다. 이 지도는 결정과 인계 경계를 소유하고 기존 구현 명세를 링크한다. 작업 트리의 인쇄물 관련 수정은 별도 진행 작업이므로 건드리지 않는다.

## Not yet specified

- 실제 유입과 전환의 이탈 위치가 드러나면 다음 실험의 형태·규모를 구체화한다. 아직 문구 실험, 배포 채널 확대, 가격 재방문 유도 중 어느 실험인지 정하지 않는다.
- 공개 자료와 비공개 관측이 충돌하면 추가 관측 경로가 필요할 수 있다. 접근 불가를 장애 없음이나 수요 없음으로 해석하지 않는다.
- 운영자의 콘텐츠 검토가 예상보다 오래 걸리면 검토를 줄이는 방법을 다시 찾는다. 근거가 확인되지 않은 설명으로 수량을 채우지 않는다.

## Out of scope

- 이 세션과 지도의 제품 코드 수정·배포·외부 게시 실행. 확정된 실행 명세를 별도 구현 작업으로 넘긴다.
- 검색 순위·색인 수·유입량의 보장, 240개 품종의 전면 본문 작성, 새로운 가격 데이터 출처·수집 파이프라인 도입.
- 근거가 약한 llms.txt 제작·전용 최적화(원안 마지막 항목). 이번 목적지의 필수 경로에 넣지 않으며 새 근거가 나오면 별도 노력으로 검토한다.
- 2개월 뒤 실험 성과 판정 자체. 이 지도에서는 이후 판정할 관측 기간·최소 표본·중단 기준까지만 정한다.
