# 07. 그림 어드민: 기존 품종 편집

Status: ready-for-agent
Type: task
Blocked by: 06 (resolved)

## 목적

기존 품종의 표시명, 별칭, 카테고리, 제철 달, 대표 달, 근거, 연결된 그림을 어드민에서 고친다 (명세 결정 18).

## 할 일

- [ ] 품종 목록(검색, 카테고리·제철 검증 상태 필터)과 편집 폼. 06의 폼을 다시 쓴다.
- [ ] 품종 ID는 읽기 전용이다. 삭제 버튼은 두지 않는다. 달력에서 빼려면 제철 미검증으로 내린다.
- [ ] 제철 달을 바꾸면 근거 출처와 확인일을 다시 받는다. 이전 근거는 지우지 않고 남긴다.
- [ ] 저장 뒤 "웹에 반영"으로 이어진다.

## 완료 기준

- 품종 하나의 별칭을 더하고 반영하면 검색에 걸리고, 품종 원본 diff가 그 항목만이다.
- 품종 ID를 바꾸거나 품종을 지울 길이 화면에 없다.
