# 04. foods:sync 개편

Status: ready-for-agent
Type: task (prototypes/가 있는 기기에서)
Blocked by: 02 (resolved), 03 (resolved)

## 목적

`pnpm foods:sync` 한 번으로 품종 목록, 웹 SVG, 그림 목록, 경계값, 출처 기록을 만들고, 문제가 있으면 기존 산출물을 지킨다 (명세 결정 9~12).

## 할 일

- [ ] 검사를 순수 함수로 빼고 테스트를 먼저 쓴다: 중복 ID, 가리키는 그림의 원본 누락, 제철 검증됐는데 달이 빈 품종(근거가 빈 품종은 개수만 알린다), 옛 ID(`renamed-foods.ts`)와의 충돌, 미검수 그림 참조.
- [ ] 내보낼 그림을 "검수 완료이고 품종 원본·이유식 그림 목록·전통 음식·회 데이터 중 하나라도 가리키는 그림"으로 정한다. `CANDIDATE_FOOD_IDS`를 없앤다.
- [ ] 임시 폴더에 모두 생성한 뒤 검사하고, 통과하면 한 번에 교체한다. 실패하면 고칠 항목을 품종 ID·그림 ID와 함께 출력하고 0이 아닌 코드로 끝낸다.
- [ ] `prototypes/`가 없으면 품종 목록 생성과 검사만 하고 그림 렌더를 건너뛰었다고 출력한다.
- [ ] `foods:bounds`는 그대로 둔다. `build:foods` 스크립트는 `foods:sync`로 합치거나 그 일부를 부르게 한다.
- [ ] 어드민(06)이 부를 수 있게 생성과 검사를 함수로 내보낸다.

## 완료 기준

- 깨끗한 상태에서 돌리면 산출물이 01의 해시와 같다(의도한 차이는 적는다).
- 품종 원본에 중복 ID를 넣거나 없는 그림을 가리키게 하면 오류가 항목을 짚고, `git status`에 산출물 변경이 없다.
- `pnpm typecheck`, `pnpm lint`, `pnpm test` 통과.
