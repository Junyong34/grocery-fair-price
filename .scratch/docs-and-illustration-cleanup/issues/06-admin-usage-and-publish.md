# 06. 그림 어드민: 용도 지정과 웹에 반영

Status: ready-for-agent
Type: task (prototypes/가 있는 기기에서)
Blocked by: 04 (resolved), 05 (resolved)

## 목적

사용자가 그림의 용도(제철, 이유식)를 정하고 웹에 반영한다 (명세 결정 15~17).

## 할 일

- [ ] 제철로 지정: 새 품종을 만들거나 기존 품종에 그림을 연결한다. 품종 ID(새 품종일 때만), 표시명, 별칭, 카테고리, 제철 달, 대표 달, 근거 출처, 확인일을 받는다. 새 품종 ID는 기존 ID·옛 ID와 겹치면 막는다.
- [ ] 근거 출처나 확인일이 비면 제철 미검증으로 저장하고, 제철달력에 나가지 않는다고 화면에 알린다.
- [ ] 이유식으로 지정: 그림을 이유식 그림 목록(03의 JSON)에 연결한다. 궁합·월령 본문은 고치지 않는다.
- [ ] 저장은 품종 원본과 이유식 그림 목록을 쓴다. 쓰는 JSON의 정렬과 들여쓰기를 고정해 diff가 바뀐 항목만 보이게 한다.
- [ ] "웹에 반영" 버튼: 04의 생성과 검사를 돌리고, 실패하면 고칠 항목 목록을 화면에 보여 준다. 성공하면 바뀐 파일 목록을 보여 준다. 커밋은 하지 않는다.

## 완료 기준

- 새 그림을 검수 완료 + 제철(근거 있음)로 저장하고 반영하면 `/seasonal`에 나온다(375 · 1280).
- 같은 그림을 근거 없이 저장하면 제철달력에 없다.
- 이유식만 지정한 그림은 이유식 화면에만 나오고 품종 원본에 없다.
