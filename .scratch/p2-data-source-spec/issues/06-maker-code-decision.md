2. 필요하다면
   - A. 상품명을 보고 사람이 매핑표를 만든다 (130개)
   - B. 한국소비자원(043-880-5786)에 코드표를 문의한다
3. 상품을 **품종**에 연결할 때 제조사 코드가 도움이 되는가? (예: 469 = 신선식품 29개)
