# 07. 라이선스·출처 표기 확인

Status: resolved (2026-11-27. 남은 것: 참가격 출처 문구에 공공누리 제1유형·링크 넣기, KAMIS 홈페이지 약관과의 관계는 유료 기능 전에 aT 문의)
Type: research
Blocked by: -

## 목적

`public-data-survey.md` 4장의 "KAMIS·축평원 공공누리 유형" 항목을 해소하고, 화면에 넣을 출처 표기 문구를 확정한다.

## 할 일

- [ ] 3개 API(data.go.kr 페이지 기준)의 이용허락범위, 공공누리 유형 확인
  - KAMIS `B552845/perDay/price`, 축평원 15000577, 참가격 15158701
- [ ] 상업적 이용, 가공·재배포(예: 가공한 시세를 우리 API로 제공)가 가능한지 근거 문구와 함께 정리
- [ ] 출처 표기 문구 초안: 출처별 한 줄, 기준일 포함 형식
- [ ] 개발계정 → 운영계정 전환 절차와 한도 증설 신청 조건
- [ ] KAMIS 자체 사이트(kamis.or.kr) 이용약관에 데이터 활용 제한이 있는지 (05와 연결)

## 산출물

- 각 출처 문서(02~04)의 "라이선스·출처 표기" 절에 반영
- 확인할 수 없는 항목은 data.go.kr 문의 필요로 표시

## 완료 기준

- 3개 출처 모두 유형과 근거 URL이 적혀 있다.

## Answer

2026-11-27 data.go.kr 데이터셋 페이지·정책·FAQ, 공공누리 제1유형 안내, kamis.or.kr 약관을 직접 받아 읽었다. 정리는 [public-data-survey.md 4장](../../../grocery-price/docs/10-research/public-data-survey.md), 출처별은 [kamis.md 12장](../../../grocery-price/docs/30-data/sources/kamis.md) · [ekape.md 15장](../../../grocery-price/docs/30-data/sources/ekape.md) · [chamgagyeok.md 16장](../../../grocery-price/docs/30-data/sources/chamgagyeok.md).

| 출처 | 이용허락범위 (페이지 표기) | 상업 이용 | 가공 · 재배포 | 출처 표시 |
|---|---|---|---|---|
| KAMIS [15156057](https://www.data.go.kr/data/15156057/openapi.do) | "이용허락범위 제한 없음" (공공누리 없음) | 가능 | 가공 후 제공 가능. 원자료 그대로 재배포는 명시 문구 미확인 | 의무 없음, 표시함 |
| 축평원 [15000577](https://www.data.go.kr/data/15000577/openapi.do) | "이용허락범위 제한 없음" (공공누리 없음) | 가능 | KAMIS와 같음 | 의무 없음, 표시함 |
| 참가격 [15158701](https://www.data.go.kr/data/15158701/openapi.do) | 공공누리 제1유형 (출처표시) | 가능 | 가능 | **의무 + 출처 사이트 링크** |

- 상업 이용 근거: data.go.kr FAQ "상업적 이용이 원칙적으로 허용됩니다" (공공데이터법 제3조). 공공누리 제1유형 "영리 목적으로 이용할 수 있습니다".
- **KAMIS 홈페이지 약관이 더 좁다.** 저작권보호정책은 수익 목적이면 사전 협의·허락을 요구한다. 우리는 data.go.kr API만 쓰므로 그 조건을 따른다고 보지만(의견), 광고·유료 기능 전에 aT에 서면 확인이 필요하다 (**미확인, 문의 필요**).
- 운영계정: 세 페이지 모두 "활용사례 등록시 신청하면 트래픽 증가 가능", 운영단계 심의 자동승인. FAQ 절차는 개발계정 → 운영계정 전환 뒤 트래픽 상향 요청, 운영계정은 변경신청으로 증설. 로그인 뒤 화면 순서·운영계정 기본 한도·증설 상한은 **미확인**. 지금 호출량으로는 필요 없다.
- 축평원 자체 사이트 약관은 보지 않았다 (**미확인**).

출처 표기 문구 초안 (`{기관} {서비스} · {기준일} 조사`):
- `한국농수산식품유통공사 KAMIS 농산물유통정보 · 2026-11-26 조사`
- `축산물품질평가원 축산물유통정보 · 2026-11-26 조사`
- `한국소비자원 참가격 · 2026-11-20 조사 · 공공누리 제1유형(출처표시)` + www.price.go.kr 링크

지금 웹앱 문구와의 차이 (코드는 고치지 않았다. 제안만):
1. `apps/web/features/settings/copy.ts` `SOURCES_COPY` 참가격 줄에 이용조건("공공누리 제1유형 · 출처표시")과 www.price.go.kr 링크가 없다. 제1유형의 링크 조건을 채우려면 넣어야 한다. **가장 먼저 고칠 것.**
2. 같은 파일 KAMIS `what: "농축산물 소매 · 도매 시세"`는 실제와 다르다. 수집은 소매(`se_cd 01`)만이고 수산물도 받는다. `"농축수산물 소매 시세"`를 제안한다.
3. 출처 화면에 출처별 기준일(마지막 조사일)이 없다. payload에 출처별 최신 상태(`freshness`)가 아직 없어(pipeline.md 4-1) 그것이 생기면 붙인다. 화면 안 짧은 표기(`listBasisLine`, `PRICE_COPY.detail.basis`, `basis.source` "KAMIS"/"축평원"/"참가격")는 조사일을 이미 함께 쓰고 출처 화면으로 링크하므로 그대로 둔다.
4. 출처 화면 `intro`에 "평소가와 판정은 장볼날이 계산한 값이에요. 각 기관의 공식 자료가 아니에요." 같은 한 줄을 더한다. 제1유형의 후원 오인 금지와 수치 변경 착오 금지를 함께 덮는다.
5. 각 출처 이름에 data.go.kr 데이터셋 페이지 링크를 단다 (KAMIS·축평원은 의무는 아니다).

문서 정정: `kamis.md` 12장의 "payload 표기 '한국농수산식품유통공사 KAMIS'(`attribution`)"는 실제 payload에 없는 필드라 지웠다.
