# 09. 보조 출처: 뉴스 수집 경로와 약관

Status: ready-for-agent
Type: research
Blocked by: -

## 목적

뉴스 키워드 급증을 **이슈 신호**로 쓸 수 있는지, 쓴다면 어떤 경로로 합법적으로 수집할지 정한다. `domain-model.md` 10장이 P2로 넘긴 질문이다. 산출물은 `sources/context.md`의 해당 절이다.

## 할 일

- [ ] 후보 경로별 조사
  - 뉴스 검색 API (네이버 등): 결과 저장·재가공 약관, 호출 한도
  - 언론사 RSS: 이용 조건
  - 한국언론진흥재단 빅카인즈(뉴스 빅데이터) 등 공공 서비스
- [ ] 각 경로의 약관 조항을 근거로 "키워드 빈도 집계만 저장" 같은 사용 방식이 허용되는지 판단
- [ ] ADR 0001(크롤링 안 함)과 충돌하지 않는지 확인. 충돌하면 명시
- [ ] 추천 경로 1개와 이유, 또는 "MVP에서는 뉴스 수집 안 함"

## 완료 기준

- 경로별 허용 여부와 약관 근거가 표로 있고, 추천이 한 문장으로 있다.
