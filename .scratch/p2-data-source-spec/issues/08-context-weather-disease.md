# 08. 보조 출처: 기상·가축 질병

Status: ready-for-agent
Type: research
Blocked by: -

> 후순위 (2026-10-19): 가격 이슈·제철 보조 출처는 확장 단계 E4로 미뤘다. MVP 1순위(판정)에 직접 필요하지 않다. P2 마무리(11)의 선행이 아니다.

## 목적

**가격 이슈**(장마, 한파, 조류독감, 아프리카돼지열병)의 **이슈 신호**를 자동으로 얻을 수 있는 공공 API를 조사한다. 산출물은 `grocery-price/docs/30-data/sources/context.md`의 해당 절이다.

## 할 일

- [ ] 기상: 기상청 특보(호우, 태풍, 한파, 폭염) API와 관측 API. data.go.kr 제공 여부, 요청·응답 필드, 갱신 주기, 한도, 라이선스
- [ ] 가축 질병: 가축질병 발생 현황(고병원성 AI, ASF, 구제역) 제공 경로. 농림축산검역본부 또는 data.go.kr
- [ ] 각 후보를 한 줄로 평가: 어떤 이슈 신호를 만들 수 있는가, 지역 단위인가, 지연은 얼마인가
- [ ] 가능하면 키 없이도 되는지, 현재 `.env` 키로 호출 가능한지 실호출 1회씩

## 하지 않는 것

- 이슈 후보 판단 규칙(임계값). 이는 P5의 일이다.

## 완료 기준

- 이슈 유형별로 쓸 수 있는 API 후보 1개 이상, 또는 "공공 API 없음"이 근거와 함께 적혀 있다.
