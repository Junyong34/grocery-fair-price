## 포함할 내용

- [ ] 엔드포인트(http, https 아님), 요청 파라미터, 축종 코드와 부위 코드 전체 목록
  - 목록 근거: `reference/public-data/ekape/openapi-guide.txt`
- [ ] 응답 필드 표 (도메인 개념 연결 또는 "미사용")
  - `grdNm`은 등급과 원산지가 한 필드에 섞여 있다. **규격** 개념으로 어떻게 나눌지 적는다.
  - `regionPrc1~17`은 MVP 미사용 여부를 명시한다.
- [ ] 같은 `itemCd`에 item이 여러 개 오는 이유 (01의 확인 결과)
- [ ] 갱신 시각 (미확인 항목). 몇 시에 당일 값이 올라오는지 시간대별 호출로 확인
- [ ] 과거 데이터 조회 범위
- [ ] 호출 한도(1,000건/일)와 축종×부위×등급 조합 수 기준 일일 호출량 추정
- [ ] 같은 서비스의 다른 기능(순별·월별·연도별 소비자가격) 중 쓸 만한 것 한 줄 평가
- [ ] 갱신 지연이 있는지 (휴일·도축 없는 날)

## 완료 기준

- 모든 응답 필드가 도메인 개념에 연결되거나 "미사용"이다.
- 축평원 갱신 시각이 시각으로 적혀 있다.
