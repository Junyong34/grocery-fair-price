# 03. 축평원 출처 문서

Status: ready-for-agent
Type: task
Blocked by: 01

## 목적

`grocery-price/docs/30-data/sources/ekape.md`를 만든다.

## 포함할 내용

- [x] 엔드포인트(http, https 아님), 요청 파라미터, 축종 코드와 부위 코드 전체 목록
  - 목록 근거: `reference/public-data/ekape/openapi-guide.txt`

  - `grdNm`은 등급과 원산지가 한 필드에 섞여 있다. **규격** 개념으로 어떻게 나눌지 적는다.
  - `regionPrc1~17`은 MVP 미사용 여부를 명시한다.
- [x] 같은 `itemCd`에 item이 여러 개 오는 이유 (01의 확인 결과)
- [ ] 갱신 시각 (미확인 항목). 몇 시에 당일 값이 올라오는지 시간대별 호출로 확인
- [x] 과거 데이터 조회 범위
- [x] 호출 한도(1,000건/일)와 축종×부위×등급 조합 수 기준 일일 호출량 추정
- [x] 같은 서비스의 다른 기능(순별·월별·연도별 소비자가격) 중 쓸 만한 것 한 줄 평가
- [x] 갱신 지연이 있는지 (휴일·도축 없는 날)

## 완료 기준

- 모든 응답 필드가 도메인 개념에 연결되거나 "미사용"이다.
- 축평원 갱신 시각이 시각으로 적혀 있다.

## Answer

산출물: [`grocery-price/docs/30-data/sources/ekape.md`](../../../grocery-price/docs/30-data/sources/ekape.md) (2026-10-19, 축평원 49회 + KAMIS 3회 실호출. 응답은 저장소에 넣지 않음)

- 엔드포인트는 http, `itemCd`를 빼면 축종 전체가 온다. 품목코드는 18개로 명세(13개)보다 많고(수입 소고기 29·62·68, 닭 99, 계란 23), **축종 안에서만 유일**하다 (68 = 돼지 목심 / 수입 척아이롤(냉동)). 하루 27개 조합.
- 응답 필드는 모두 도메인 개념에 연결했거나 "미사용"이다. `regionPrc1~17`, `maxPrc`/`minPrc`(= 시도 최고·최저)는 MVP 미사용.
- `grdNm`은 축종으로 뜻을 정한다: 소 = 규격(등급 1+, 1), 수입 소고기 = 원산지라 **품종**을 가름, 계란 `일반란` = 기본 규격, `구분없음` = 기본 규격.
- 같은 `itemCd`의 여러 item = `grdNm` 수 × (당일 행, 평년 행). **평년 행에는 날짜가 없고 당일 행보다 먼저 나온다.** 수집 성공은 "당일 행 1개 이상"으로 판정한다.
- 과거: 전국 값은 2012-06까지 있음(2010-01은 없음), 시도 값은 2022-01부터. 하루 단위 조회만 된다.
- 호출량: 매일 21회(축종 7 × 3일). 5년 채우기 12,782회 = 예산 800회로 16일.
- 휴일: 2026년은 주말·명절·공휴일에도 값이 있고 매일 바뀐다. 2021년 이전은 공휴일이 비어 있다. 소 갈비는 1주일 넘게 같은 값(표본 부족에 따른 갱신 지연 의심).
- KAMIS 축산(부류 500) 소매 값은 축평원과 **같은 숫자**다 (10-18 돼지 4개 부위, 소 등심·안심 전국·서울 일치). 다만 KAMIS에는 소 1++등급이 있고 평년이 없다.
- 다른 기능: 순별은 순 단위 평년이 필요하면 쓸 만함, 월별은 MVP 불필요, 연도별 미사용.

**완료 기준 미충족 1건**: 갱신 시각을 "D일 16:30 이후 ~ D+1일 10:10 이전"까지만 좁혔다. 응답·KAMIS 축산 행에 등록 시각이 없어, D일 18:00·21:00, D+1일 00:30·03:00·06:00·08:00에 1회씩 호출해야 시각으로 적을 수 있다 (출처 문서 9장). 그래서 Status는 ready-for-agent로 둔다.
