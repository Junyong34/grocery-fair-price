# 09. 제철 달력과 품종 상세의 대표 이미지

Status: resolved (2026-11-18)
Blocked by: 06

- [x] 다운로드 목록의 연도 필터 위에 게시된 달력 미리보기를 표시하고 대표 이미지로 연결한다.
- [x] 그림이 있는 품종의 전체 페이지에서 본문 그림을 대표 이미지로 연결한다.
- [x] 화면과 서버 HTML을 검증한다.

## Comments

- 최신 게시 연도의 연간 달력 미리보기를 우선하고, 없으면 같은 연도의 월간 달력 미리보기를 사용한다. 사용 가능한 이미지가 없으면 미리보기와 대표 이미지 설정을 생략한다.
- Chrome 375px·1280px에서 미리보기의 위치, 연도 전환, 상세 링크를 확인했다. 콘솔 오류와 하이드레이션 경고는 없었다.
- 다운로드 목록과 근대·상추·꼬막·대저토마토·조 상세의 서버 HTML에서 대표 이미지 URL과 본문 그림의 주소가 일치하고 이미지가 정상 응답하는 것을 확인했다. 현재 품종 256개의 그림 파일이 모두 있어 그림 없는 품종의 실페이지는 확인할 수 없었다.
- 루트의 `pnpm typecheck`, `pnpm lint`, `pnpm test`를 통과했다. 기존 UI 스크립트의 린트 경고 4건이 있었다. 운영 배포와 Google 썸네일 노출은 확인 범위에서 제외했다.
