# 11. 흩어진 배치 드래그와 겹침 해소

Status: ready-for-agent
Blocked by: 04

## 목적

2a의 흩어진 품종을 끌어 옮기고, 겹치면 주변 품종이 밀려나게 한다. 옮긴 배치는 기기에 남긴다. 규칙은 spec "흩어진 배치와 드래그"에 있다.

## 할 일

- [ ] 겹침 해소 순수 함수(`packages/ui`): 원(중심, 반지름) 배열, 고정할 id, 영역을 받아 완화 반복으로 겹침을 푼다. 고정한 원은 움직이지 않고, 모두 영역 안에 남고, 반복 횟수에 상한이 있다. 테스트를 먼저 쓴다.
- [ ] 저장 배치 병합 순수 함수(`packages/seasonal/src/layout/`): 저장된 배치와 현재 품종 목록을 받아 남은 위치는 유지하고, 빠진 품종은 지우고, 새 품종은 빈자리에 넣고, 크기를 다시 계산한다. 테스트를 먼저 쓴다.
- [ ] 배치 store(`features/seasonal`, persist): (달, 구간) → `{id, x, y}[]`.
- [ ] `ScatterField`에 포인터 상호작용을 붙인다(`motion`): 6px 임계값으로 탭과 드래그를 나누고, 모바일은 250ms 길게 누른 뒤 시작한다. 끄는 동안 실시간 밀어내기, 놓으면 스프링. 끄는 품종은 맨 위로 올라오고 살짝 커진다.
- [ ] "원래대로" 버튼: 그 달을 옮긴 적이 있을 때만 보이고, 누르면 시드 배치로 스프링 복귀한다.
- [ ] 히어로와 그 달 섹션이 같은 배치를 쓰는지 확인한다.
- [ ] 줄인 모션 설정에서는 스프링 없이 바로 자리를 잡는다.

## 완료 조건

- 모바일에서 세로 스크롤이 드래그로 오인되지 않는다(실기기 또는 agent-browser 터치 에뮬레이션).
- 끌지 않고 누르면 1i가 열린다.
- 새로고침 뒤에도 옮긴 배치가 남고, 품종 목록을 바꿔도 깨지지 않는다(병합 테스트).
- 20개 품종을 끌 때 프레임 저하가 없다.
