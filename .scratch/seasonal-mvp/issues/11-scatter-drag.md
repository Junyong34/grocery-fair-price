# 11. 흩어진 배치 드래그와 겹침 해소

Status: resolved
Blocked by: 04

## 목적

2a의 흩어진 품종을 끌어 옮기고, 겹치면 주변 품종이 밀려나게 한다. 옮긴 배치는 기기에 남긴다. 규칙은 spec "흩어진 배치와 드래그"에 있다.

## 할 일

- [x] 겹침 해소 순수 함수(`packages/ui`): 원(중심, 반지름) 배열, 고정할 id, 영역을 받아 완화 반복으로 겹침을 푼다. 고정한 원은 움직이지 않고, 모두 영역 안에 남고, 반복 횟수에 상한이 있다. 테스트를 먼저 쓴다.
- [x] 저장 배치 병합 순수 함수(`packages/seasonal/src/layout/`): 저장된 배치와 현재 품종 목록을 받아 남은 위치는 유지하고, 빠진 품종은 지우고, 새 품종은 빈자리에 넣고, 크기를 다시 계산한다. 테스트를 먼저 쓴다.
- [x] 배치 store(`features/seasonal`, persist): (달, 구간) → `{id, x, y}[]`.
- [x] `ScatterField`에 포인터 상호작용을 붙인다(`motion`): 6px 임계값으로 탭과 드래그를 나누고, 모바일은 250ms 길게 누른 뒤 시작한다. 끄는 동안 실시간 밀어내기, 놓으면 스프링. 끄는 품종은 맨 위로 올라오고 살짝 커진다.
- [x] "원래대로" 버튼: 그 달을 옮긴 적이 있을 때만 보이고, 누르면 시드 배치로 스프링 복귀한다.
- [x] 히어로와 그 달 섹션이 같은 배치를 쓰는지 확인한다.
- [x] 줄인 모션 설정에서는 스프링 없이 바로 자리를 잡는다.

## 완료 조건

- 모바일에서 세로 스크롤이 드래그로 오인되지 않는다(실기기 또는 agent-browser 터치 에뮬레이션).
- 끌지 않고 누르면 1i가 열린다.
- 새로고침 뒤에도 옮긴 배치가 남고, 품종 목록을 바꿔도 깨지지 않는다(병합 테스트).
- 20개 품종을 끌 때 프레임 저하가 없다.

## Answer

2026-10-14 완료.

- 겹침 해소 `packages/ui/src/lib/geometry/relax-circles.ts`(테스트 4개, `packages/ui`에 vitest 추가): 겹친 원 쌍을 밀어내는 반복(최대 8회), 고정 원은 안 움직임, 원 전체가 영역 안. 앞의 두 테스트는 실패를 먼저 봤고, "겹치지 않으면 그대로"·"gap" 테스트는 첫 구현으로 바로 통과했다.
- 병합 `packages/seasonal/src/layout/merge-saved.ts`(테스트 3개): 저장된 품종은 자리 유지(크기·기울기는 지금 시드), 빠진 품종 삭제, 새 품종은 시드와 같은 후보 탐색으로 빈자리. 이를 위해 `scatter.ts`에서 `findOpenSpot`·`seededRandom`·`labelHeight`를 뽑아냈다(난수 호출 순서가 같아 시드 배치는 그대로).
- 화면: `ScatterField`(서버)가 시드를 계산하고 `DraggableScatter`(클라이언트)가 위치·포인터를 맡는다. 첫 화면·SSR은 전과 같다.
  - 마우스는 6px, 손가락은 250ms 누른 뒤 끌기. 끄는 동안 rAF마다 `relaxCircles`(끄는 그림 고정), 놓으면 한 번 더 푼 뒤 저장. 끈 뒤의 click은 막는다. 링크의 HTML 기본 드래그와 iOS 길게 누르기 메뉴는 끈다.
  - 손가락으로 끄는 동안 스크롤은 비수동 `touchmove`에서 막는다. 영역은 `touch-pan-y`.
  - 주변 그림은 CSS transition(left/top, 300ms, 살짝 튀는 곡선)으로 따라온다. 줄인 모션이면 transition이 없다. spec은 motion 라이브러리를 적었지만 apps/web에 의존성을 늘리지 않고 CSS로 충분했다.
  - 저장: zustand persist `seasonal:scatter`, 키 `달:구간`. 히어로와 그 달 섹션이 같은 키라 함께 바뀐다. 옮긴 적이 있으면 "원래대로".
- 검증
  - 데스크톱 실제 마우스 끌기: 사과를 고등어 자리로 → 고등어 81px·무 19px 밀림, 이동 없음(클릭 막힘), `10:desktop` 저장, 새로고침 뒤 유지, 히어로·10월 섹션 같은 자리, 그냥 누르면 늙은 호박 시트, "원래대로" → 시드로 복귀·저장 삭제.
  - 손가락: agent-browser에 터치 입력이 없어 합성 PointerEvent(pointerType touch)로 확인했다. 바로 움직이면 끌기 아님, 300ms 뒤 움직이면 끌기·`10:mobile` 저장. **실기기에서 브라우저 스크롤과 실제로 겹치지 않는지는 확인하지 못했다**(12에서 실기기 확인).
  - 성능: 11월(20개) 2.5초 끌기 동안 프레임 중앙값 16.7ms, p95 16.8ms, 33ms 초과 0(헤드리스 Chrome, Mac).
