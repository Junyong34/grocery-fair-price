## 목적

메인 화면(명세 3.1)을 만든다. 드래그는 11에서 얹는다. 여기서는 시드 배치만 보인다.

## 할 일

- [ ] **시드 배치** `packages/seasonal/src/layout/scatter.ts`: 명세의 `scat()`를 옮기되, 결과를 0..1 정규화 좌표로 내고 시드에 픽셀 폭 대신 구간 id를 넣는다. 같은 입력이면 같은 결과가 나온다는 것, 영역 밖으로 나가지 않는다는 것, 개수가 많을수록 작아진다는 것을 테스트로 먼저 쓴다.
- [ ] **`ScatterField`**(feature 컴포넌트): 고정 비율 영역에 정규화 좌표를 확대해 놓는다. 품종마다 `FoodImage`, 라벨, 회전, ✓ 배지가 있고 1i 링크다. 서버 컴포넌트로 렌더할 수 있게 한다(배치 계산에 클라이언트 JS가 필요 없다).
- [ ] 히어로와 그 달 섹션은 같은 비율 영역을 쓰고 배치를 공유한다(모바일 339:240, 데스크톱 736:300).
- [ ] 히어로, 월 섹션 × 12, 미니 달력(공휴일 점, 절기 없음), 푸터, 스티키 인디케이터, 모바일 월 레일(즉시 이동과 도착 섹션 fadeIn).
- [ ] 스크롤 위치로 활성 달 계산(영역 높이 45% 규칙).
- [ ] `routes.seasonal.rootAt(month)` → `/seasonal#month-N`. 해시로 들어오면 즉시 그 달로 이동한다.
- [ ] **설정**(⚙): 공휴일 표시, 먹은 품종 표시 스위치. 모바일은 `BottomSheet`, 데스크톱은 상단에서 내려오는 400px 패널이다. 달력 다운로드는 넣지 않는다.
- [ ] **데스크톱 좌측 패널**: `pnpm ui:add https://cojeev.com/ui/r/option-wheel.json`. 영어 문구를 props로 빼고, 라벨은 "10월 · 17가지" 형식으로 쓴다. 스크롤과 휠 선택을 양방향으로 맞추고, 연속 선택은 150ms 디바운스한다.
- [ ] `/examples/option-wheel`: `arc`와 `reel`을 실제 월 데이터로 나란히 보인다. 사용자가 고른 결과를 spec "열린 질문"에서 "결정"으로 옮긴다.
- [ ] "오늘"은 서울 기준으로 요청 시점에 계산한다(`apps/web/docs/nextjs-16-patterns.md` 5.2).
