# 05. 1i 품종 상세

Status: ready-for-agent
Blocked by: 03

## 목적

명세가 비워 둔 1i 화면을 spec "화면별"의 구성대로 만든다.

## 할 일

- [ ] `foods/[food]`의 `generateStaticParams`를 `foods.ts` 전체 id로 바꾸고, 없는 id는 `notFound()`로 막는다(파일의 TODO).
- [ ] 구성: 큰 일러스트(`motion` 변형 `<img>`. CSS 키프레임이 SVG 안에 있어 GSAP이 필요 없다), 품종명과 계절 태그, 12칸 제철 막대, 먹음 기록 토글(+1 pop), 관련 명절 링크(없으면 생략), 같은 달 다른 품종 가로 스크롤, "가격 보기" 비활성('준비 중').
- [ ] 같은 내용을 세 껍데기에 넣는다: 모바일 하단 시트(`@sheet` 가로채기), 데스크톱 오른쪽 패널(cojeev `sheet`, `pnpm ui:add`), 주소로 직접 연 전체 페이지.
- [ ] 줄인 모션 설정이면 일러스트 움직임과 pop을 끈다.

## 완료 조건

- 2a에서 품종을 누르면 시트(모바일) 또는 패널(데스크톱)이 열리고, 닫으면 스크롤 위치가 그대로다.
- 상세에서 기록하면 뒤 화면의 ✓가 바로 바뀐다.
