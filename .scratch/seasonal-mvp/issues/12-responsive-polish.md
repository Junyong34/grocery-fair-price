# 12. 데스크톱·태블릿 변형 정리

Status: ready-for-agent
Blocked by: 04, 05, 06, 07, 08, 09, 10

## 목적

화면별로 따로 만든 반응형을 한 번에 맞춘다.

## 할 일

- [ ] 태블릿(600–1023) 구간: 흩어진 배치 영역 비율을 정하고 구간 id를 추가한다. 2b 3열, 3a 2×2와 상세 6열(명세 반응형 항목).
- [ ] 모든 화면에서 내비, 헤더, 2차 탭이 구간 경계(599/600, 1023/1024)에서 깨지지 않는지 확인한다.
- [ ] 모바일 월 레일 사용성을 판단한다. 불편하면 "스티키 인디케이터 → 휠 하단 시트" 후속 티켓을 만든다.
- [ ] `improve-animations` 스킬로 모션을 한 번 점검한다(줄인 모션 설정 포함).

## 완료 조건

- 375, 768, 1280 세 폭에서 모든 제철 라우트 스크린샷.
