# 05. P2 품종 검색 + 결과 없음

Status: ready-for-agent
Type: task (AFK)
Blocked by: 04

## 할 일

- [ ] `/search?q=` (noindex 등록). 들어오면 입력칸에 바로 포커스, 뒤로 가기로 메인
- [ ] 치는 동안 결과가 바뀐다 (서버가 내려준 `searchIndex`로 클라이언트에서 거른다). 초성, 품목("어떤 호박인가요?"), 별칭("대패삼겹"는 이 품종으로 찾았어요), 오타("혹시 이 품종인가요?")
- [ ] 빈 검색어: 최근 본 품종 + 자주 사는 품종
- [ ] 결과 없음: "트러플는 아직 판정하지 않아요", 찾는 방법, 카테고리 알약, 자주 사는 품종. "찾으신 말은 기록해 두고" 문구는 넣지 않는다
- [ ] 검색어를 URL `q`와 맞춘다 (replace, 기록을 쌓지 않는다)
