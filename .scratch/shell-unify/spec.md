## 1. 하단 내비: 고정 4칸

- 어느 화면에서나 같은 4칸: **시세 · 제철달력 · 담은 품종 · 나의 식탁**. `MenuArea`별 메뉴(`menus.ts`의 `price` · `seasonal`)를 없애고 목록 하나로 둔다.
- 칸 순서와 위치는 바뀌지 않는다. 화면 상태에 따라 칸을 숨기거나 끄지 않는다(HIG Tab bars, M3 Navigation bar).
- 활성 판정:
  - 시세: `/`, `/search`, `/prices/*`
  - 제철달력: `/seasonal`, `/seasonal/months/*`, `/seasonal/seasons/*`, `/seasonal/festivals/*`, `/seasonal/foods/*`, `/seasonal/downloads/*`
  - 담은 품종: `/basket`
  - 나의 식탁: `/seasonal/my-table`
  - `/settings/*`, `/privacy`: 어느 칸도 활성이 아니다.
- 담은 품종 배지(개수, 0이면 숨김)는 모든 화면에서 보인다.
- "계절" 칸은 없어진다. 계절 · 명절은 제철달력 안 탭으로 옮긴다(2장).
- 모양은 지금의 떠 있는 크림 트레이(칸 72px)를 그대로 쓴다. 4칸 = 288px로 375px에 들어간다.
- 스크롤해도 숨기지 않는다.
- 데스크톱(≥1024) 헤더 안 주요 메뉴도 같은 4개다.

## 2. 제철달력 탭: 이달 · 월별 · 계절 · 명절

- 2차 탭 두 벌(`ThisMonthTabs` 이달|월별 보기, `SeasonTabs` 계절|명절)을 한 벌 **이달 · 월별 · 계절 · 명절**로 합친다. 라우트 그룹 `(this-month)`와 `(season)`이 같은 탭 줄을 쓴다. URL은 바꾸지 않는다.
- 탭 이름 "월별 보기"는 "월별"로 줄인다.
- 탭 줄은 4장의 스티키 규칙을 따른다. 헤더 안에 작은 탭을 접어 넣는 지금 방식(`HeaderSubTabs`, 본문 탭을 흐리게 지우는 `useFadeUnderHeader`)은 없앤다.
- 1h 나의 식탁, 1i, 내려받기에는 탭 줄이 없다.

화면은 아래 타입 중 하나를 쓴다. 높이는 48px다(시트는 시트 안).

| 타입 | 모양 | 쓰는 화면 |
|---|---|---|
| 루트 | 로고 · (여백) · 🔍 · ⚙ | P1, P4, 2a, 2b 열두 달 · 그 달, 3a 히어로 · 계절 상세, 1g, 1h |
| 하위 | ‹ · 제목 · 액션 0~2개 | P3(‹ 품종 · + 담기), 1i 페이지(‹ 품종 · 공유), 설정, 데이터 출처, 내려받기 · 에디션 페이지 |

- 루트 헤더의 오른쪽 버튼은 모든 루트 화면에서 같다: 🔍 · ⚙. 지금 가격 화면에는 버튼이 없고, 제철에는 🔍만 있고, ⚙는 2a에만 있다. 이 차이를 없앤다.

- 하위 헤더의 ‹는 `history.length > 1`이면 뒤로 가고, 아니면 그 화면의 부모로 간다. P3 → `/`, 1i 페이지 → `/seasonal`, 설정 → `/`, 데이터 출처 → `/settings`.

- P3 하위 헤더의 제목(품종 이름)은 처음엔 숨긴다. 본문 제목 줄에 같은 이름이 크게 있어 겹치므로, 그 줄이 헤더 밑으로 지나가면 나타난다(`SubHeader` `revealAfter`). ‹ · + 담기는 처음부터 있다.
- P3의 지금 `DetailHeaderBar`(스크롤하면 로고 자리를 바꾸는 `HeaderBar` 포털)는 처음부터 하위 헤더로 그리면 필요 없어진다. `HeaderBar` 포털은 쓰는 곳이 없으면 지운다.
- 시트에 닫기 ✕ 버튼을 더한다. 지금은 손잡이 · Esc · 배경으로만 닫힌다(M3 Bottom sheets).
- 로고를 누르면 `/`로 간다(지금과 같다).
- 데스크톱(≥1024)은 지금 헤더(로고 · 주요 메뉴 · 버튼)를 유지하고, ⚙ 위치만 모든 루트 화면으로 넓힌다.

## 4. 스크롤 (SC5 + 화면별 헤더 동작)

### 4-1. 화면별 헤더 동작

헤더 동작은 화면마다 `hide-on-scroll` 또는 `pinned` 중 하나다. 경로 → 동작 표를 `shared/shell` 한 곳에 두고 셸이 그 값을 읽는다. 페이지마다 prop으로 흩지 않는다. 새 화면은 이 표에 한 줄을 더해 정한다.

| 화면 | 헤더 | 동작 | 헤더 아래 고정 줄 |
|---|---|---|---|
| P1 시세 메인 | 루트 | hide-on-scroll | 검색 입력 줄(스크롤해서 본문 검색창이 지나가면 나타남) |
| 2a 이달 | 루트 | hide-on-scroll | 탭 줄. 월 레일은 지금처럼 오른쪽 옆 |
| 2b 열두 달 · 그 달 | 루트 | hide-on-scroll | 탭 줄 + (그 달) 달 칩 |
| 3a 히어로 · 계절 상세 | 루트 | hide-on-scroll | 탭 줄 + (상세) 계절 칩 |
| 1g 명절 | 루트 | hide-on-scroll | 탭 줄 + 명절 칩 |
| P2 품종 검색 | 검색 | pinned | 없음 |
| P3 품종 상세 | 하위 | pinned | 섹션 칩(시세 · 어디서 · 왜 · 내 가격) |
| 1i 품종 상세 페이지 | 하위 | pinned | 없음 |
| 1h 나의 식탁 | 루트 | pinned | 보기 필터 줄(월별 ▾ + 달 칩) |
| P4 담은 품종 | 루트 | pinned | 없음 |
| 설정 · 데이터 출처 | 하위 | pinned | 없음 |
| 내려받기 · 에디션 페이지 | 하위 | pinned | 없음 |
| 시트 | 시트 | 해당 없음 | 시트 헤더는 시트와 함께 움직인다 |

### 4-2. 동작 규칙

- **hide-on-scroll**:
  - 아래로 스크롤하면 헤더가 위로 사라진다. 위로 스크롤하면 다시 나온다.
  - 방향은 10px 넘게 움직였을 때만 바꾼다.
  - 맨 위 8px 안에서는 늘 보인다.
  - 페이지 끝에서 튕기는 스크롤(overscroll)은 무시한다.
  - 헤더 안으로 키보드 초점이 들어가면 보인다.
- **pinned**: 헤더가 늘 보인다.
- 헤더가 숨으면 탭 줄이 맨 위로 올라붙는다. 탭 줄은 어떤 경우에도 사라지지 않는다.
- 구간 줄(달 칩 · 명절 칩 · 계절 칩 · 필터 · 섹션 칩 · P1 검색 줄)은 탭 줄 아래(탭 줄이 없으면 헤더 아래)에 한 줄 더 고정된다.
  - 본문에서 다른 스티키 구간에 들어가면 구간 줄만 그 구간의 것으로 바뀐다. 구간을 감지하는 데는 IntersectionObserver를 쓴다.
  - 구간 줄 높이는 40px다. 칩이 눈에 보이는 높이는 30px로 둬도 되지만, 누르는 영역은 44px로 잡는다.
- 스티키는 헤더를 포함해 최대 세 줄이다. 헤더가 숨은 동안은 두 줄(탭 44px + 구간 40px ≈ 86px), 헤더가 다시 나온 동안만 세 줄(≈134px)이다.
- 헤더 · 탭 줄 · 구간 줄은 한 묶음으로 움직인다. 숨을 때는 묶음 전체가 위로 48px 옮겨 간다(transform, 레이아웃을 다시 계산하지 않음).
- 지금 탭을 다시 누르면 맨 위로 스크롤한다.
- `prefers-reduced-motion`이면 슬라이드 없이 바로 바뀐다.
- 지금의 "맨 위에서 평평하다가 8px 내리면 떠 있는 둥근 바"(`useScrolledDown`, `STUCK_AT`) 모양은 다시 나타난 헤더와 pinned 헤더에 그대로 쓴다.
- 데스크톱(≥1024)은 헤더를 숨기지 않는다(pinned). 탭 줄과 구간 줄 고정은 같다.

## 5. 설정: `/settings` 하나

- ⚙는 어디서 눌러도 같은 전체 페이지 `/settings`를 연다(하위 헤더 "‹ 설정"). 2a 전용 설정 시트(`this-month/settings-panel.tsx`, `ThisMonthOnly`)는 없앤다. 데스크톱 ⚙ 팝오버도 같은 페이지로 간다.
- 섹션은 주제별로 나눈다(와이어프레임 S2). 행마다 그 설정이 영향을 주는 곳을 작은 글자로 표시한다(예: "제철달력").

| 섹션 | 항목 | 저장 |
|---|---|---|
| 화면 표시 | 공휴일 표시(토글), 먹은 음식 표시 ✓(토글), 달력 모양 4가지(썸네일), 달 이름 표기 3가지(1 · 1월 · Jan) | `seasonal:settings` (`settings-store.ts`, 그대로) |
| 내 기록 | 담은 품종 비우기(n개), 최근 본 품종 지우기, 먹음 기록 지우기(n개). 누르면 확인 시트(되돌릴 수 없음 안내) | `price:basket`, `price:recent`, `seasonal:eaten` |
| 정보 | 데이터 출처(하위 화면 `/settings/sources`), 개인정보 처리방침(`/privacy`), 버전 | |

- 맨 아래에 "설정과 기록은 이 기기에만 저장돼요"라는 안내를 둔다.
- 데이터 출처 화면에는 출처마다 무엇을 언제 조사하는지 한 줄씩 적는다. 근거는 `grocery-price/docs/30-data/sources/`다.
  - KAMIS: 농축산물 소매 · 도매 시세, 평일 조사
  - 축산물품질평가원: 축산물 소비자가격, 매일 조사
  - 참가격(한국소비자원): 판매점 판매가, 격주 조사
- 기기 저장 store는 지금처럼 모듈 안에 두고, 지우기 함수만 내보낸다(`clearBasket`, `clearRecent`, `clearEaten`). store 키 이름은 바꾸지 않는다.
- 달력 모양을 바꾸면 결과를 보러 2a로 돌아가야 한다. 그래서 설정 화면에서 썸네일을 크게 보여 준다.
- 문구는 `packages/seasonal/src/data/copy.ts`와 `packages/price/src/copy.ts` 중 맞는 곳에 둔다. 설정 화면 공통 문구는 `apps/web/features/settings/` 안 `copy.ts`에 둔다.
- 화면 코드 위치: 새 feature `apps/web/features/settings/`. features끼리 import하지 않으므로 지우기 함수와 store 훅은 `shared/`로 내리거나 이 feature가 `shared/` 것만 쓴다. 지금 `features/price/stores/` · `features/seasonal/stores/settings-store.ts`를 `shared/`로 옮길지는 티켓에서 판단한다.
- 경로 `routes.settings.root`, `routes.settings.sources`를 `shared/routes.ts`에 더하고, `shared/seo/pages.ts`에 noindex로 등록한다.

## 6. P3 "내가 본 가격 적기"
