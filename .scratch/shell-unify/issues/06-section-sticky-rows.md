# 06. 구간 줄 적용

Status: ready-for-agent
Type: task (AFK)
Blocked by: 05

## 목적

화면마다 탭 줄(또는 헤더) 아래에 고정할 구간 줄을 넣는다. 본문에서 다른 스티키 구간에 들어가면 구간 줄만 바꾼다(spec 4-1 표).

## 할 일

- [ ] 구간 줄 슬롯 API: 구간 컴포넌트가 자기 줄을 등록하고, IntersectionObserver로 화면에 들어온 구간의 줄을 보인다. 높이 40px, 칩의 누르는 영역 44px.
- [ ] 화면별 적용
  - 2b 그 달: 달 칩(지금 `month-timeline`)을 구간 줄로 고정한다.
  - 3a 계절 상세: 계절 칩
  - 1g: 명절 칩(`festival-chips`)
  - 1h: 보기 필터 줄(월별 ▾ + 달 칩). 지금의 월별/계절별 세그먼트와 달 칩을 한 줄로 합친다.
  - P3: 섹션 칩(시세 · 어디서 · 왜 · 내 가격). 누르면 그 섹션으로 스크롤한다. 섹션에 `id`를 붙인다.
  - P1: 본문 검색 입력이 화면 밖으로 지나가면 검색 입력 줄이 나타난다(누르면 `/search`).
- [ ] 2a는 구간 줄이 없다. 월 레일은 지금처럼 측면에 둔다.

## 완료 기준

- 루트 `pnpm typecheck` · `pnpm lint` · `pnpm test` 통과
- 375 · 1280에서 확인한다:
  - 각 화면에서 스크롤해도 구간 줄이 따라온다.
  - 칩을 누르면 맞는 곳으로 이동한다.
  - P3 섹션 칩 활성 표시가 스크롤 위치를 따른다.
  - 콘솔 오류가 없다.
