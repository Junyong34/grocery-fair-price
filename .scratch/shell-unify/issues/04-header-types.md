## Answer

2026-11-02. 화면 표 `shared/shell/screens.ts`(`screenOf`: 헤더 타입 + 스크롤 동작, 테스트 18건)를 만들었다. 05도 이 표를 쓴다.

- **루트**: 가격 셸에도 🔍(`search-link` → `/search`) · ⚙(`settings-link`, `shared/shell`로 옮김)가 생겼다.
- **하위**: `shared/shell/sub-header.tsx`의 `SubHeader`가 기존 `HeaderBar` 포털에 늘 `data-header-bar`를 달아 로고 · 버튼을 가린다.
  - 붙인 곳: P3(`DetailHeaderBar`가 스크롤 감지 없이 처음부터), 1i 페이지, 설정 · 데이터 출처, 내려받기 · 에디션 페이지
  - 본문 뒤로 링크와 P3 본문 ‹ · 담기는 데스크톱에서만 보인다(`max-lg:hidden`). 본문 h1은 모바일에서 `sr-only`로 남겼다.
- **검색**: `screenOf`가 search면 모바일에서 사이트 헤더를 숨기고, P2 검색 줄이 `sticky top-0`으로 헤더 자리를 맡는다.
- **시트**: `detail-sheet` 모바일에 닫기 ✕를 더했다. 2a에서 품종 시트 → ✕ → `/seasonal`로 돌아오는 것을 확인했다.
- 375 · 1280에서 P1 · P2 · P3 · P4 · 1h · 1i · 내려받기 · 설정을 찍었고 콘솔 오류는 없었다(LCP 경고만 있음).
