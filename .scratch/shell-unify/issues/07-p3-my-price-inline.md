# 07. P3 "내가 본 가격 적기"를 본문 섹션으로

Status: resolved
Type: task (AFK)
Blocked by: 06

## 목적

하단 내비 위에 겹쳐 떠 있는 "내가 본 가격 적기" 바(`features/price/variety-detail/my-price.tsx`의 `MyPriceBar`)를 본문 "내 가격" 섹션 안의 입력으로 옮긴다. 하단 내비는 그대로 둔다(spec 6장).

## 할 일

- [x] `MyPriceBar`의 떠 있는 위치를 없애고, 본문 섹션(`id="my-price"`) 안에 입력과 결과(판정 칩)를 둔다. 입력 시트가 있으면 그대로 쓴다.
- [x] 06의 섹션 칩 "내 가격"이 이 섹션으로 데려간다.
- [x] 화면 키보드가 열렸을 때 입력이 가려지지 않는지 본다(모바일 375).

## 완료 기준

- 루트 `pnpm typecheck` · `pnpm lint` · `pnpm test` 통과
- 375에서 하단 내비와 겹치는 떠 있는 바가 없다.
- 내 가격을 넣으면 판정이 나온다.
- 콘솔 오류가 없다.

## Answer

2026-11-02. `my-price.tsx`의 `MyPriceBar`(하단 sticky 떠 있는 바)를 `MyPriceSection`으로 바꿨다. 본문 섹션(`id="p3-my-price"`, 제목 "내가 본 가격")이고, 근거 한 줄 바로 위에 둔다. 판정 전(평소가 없음)이면 섹션과 섹션 칩 "내 가격"을 함께 뺀다.

- 바텀 시트 입력과 비교 카드는 그대로다.
- 확인한 것: 375에서 떠 있는 바가 없다. 섹션 칩 "내 가격"을 누르면 섹션으로 가고 칩이 활성된다. 3,000원을 넣으면 "보통 -3%" 카드가 본문에 뜬다. 375 · 1280에서 콘솔 오류가 없다.
- 화면 키보드는 실기기에서 확인하지 못했다. 입력은 바텀 시트 안이라 기존 동작과 같다.
