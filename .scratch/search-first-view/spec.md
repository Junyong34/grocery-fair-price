# 검색 한 번에 보는 가격 — 작업 분해

정부 가격 화면(참가격 생필품 가격정보)을 벤치마킹해, 필터를 고르지 않고 검색 한 번으로 판정·시세·추세가 나오는 화면을 만든다. 조사 근거는 [gov-price-sites.md](../../grocery-price/docs/10-research/gov-price-sites.md)에 있다. 2026-10-19 인터뷰로 정했다.

## 목표

- 정부 화면은 카테고리 → 품목 → 상품 → 일자·업태·지역을 고른 뒤에야 상품 하나의 숫자 표를 보여 준다.
- 우리는 사용자가 품종이나 상품을 검색하면 **바로 판정**을 보여 준다. 정부 화면에서 쓸 만한 정보(판매처 2단 평균, 업태별 최저·최고, 등락률, 할인 표시, 지도)는 가져온다.

## 범위

- 식품만(신선식품 + 가공식품). 참가격 생활용품 147개는 제외한다.
- 소매 시세와 판매가가 중심이다. 도매 시세는 조사만 하고 기능은 MVP 이후다.
- 크롤링은 하지 않는다([ADR 0001](../../grocery-price/docs/adr/0001-public-data-and-reports-over-crawling.md)). 정부 화면도 공공 API로 그린다.
- 지금은 계획과 조사만 한다. 코드는 계획·조사가 끝난 뒤 단계별 개발에서 시작한다.

## 결정된 것

| # | 결정 | 이유 |
|---|---|---|
| 1 | 검색 단위는 **품종이 먼저, 그 아래 참가격 상품** ("우유" → 우유 시세와 판정, 그 아래 상품 목록) | 판정의 중심은 품종 시세다. 상품은 "어디가 싼가"를 보탠다 |
| 2 | 첫 화면 순서: **판정** → 오늘 전국 시세·최근 추세 → 판매처·업태별 최저가(펼쳐 보기). 도매 동향 예고는 MVP 이후 | 정부 화면은 숫자만 주고 "지금 사도 되나"는 알려 주지 않는다. 이것이 차별점이다 |
| 3 | 지역 기본값은 **전국**. 결과 화면에서 바꾸고, 마지막 선택을 기기에 저장 | 위치 권한을 묻는 것은 빠른 접근에 방해가 된다 |
| 4 | 참가격 상품의 평균은 정부와 같은 **판매처별 2단 평균**. 점포→판매처 매핑표는 운영자가 관리 | 정부 화면과 숫자가 다르면 서비스가 틀렸다고 읽힌다. 평소가 계산(P5)과는 별개인 표시값이다 |
| 5 | 장기 추세는 과거분을 전부 받지 않고 **차트로 쌓아 간다**. 품종 차트(KAMIS·축평원)는 오픈 시점 기준 1년 치를 받아 두고, 상품 차트(참가격)는 2026-06-12부터 쌓인 만큼만 보여 준다 | 참가격 API는 06-12 이전을 주지 않는다. KAMIS·축평원은 1년 전을 준다 |
| 6 | 참가격 수집은 오픈 전에 미리 시작한다. **원본 응답을 파일로** 저장하고, DB가 정해지면 적재한다. 조사일 다음 날과 그다음 주 월요일에 받는다 | API가 과거를 계속 준다는 보장이 없다. 10-09분처럼 등록이 늦기도 한다. pipeline-draft의 ① 원본 보관과 같은 구조다 |
| 7 | 차트: 품종은 **시세 선 + 평소가 띠**, 상품은 **평균 선 + 최저~최고 띠**. 업태별 선은 펼쳐 보기. 기간은 1개월·3개월·1년, 기본 3개월 | 띠가 있으면 판정이 한눈에 보인다 |
| 8 | 참가격 상품은 **소분류 단위로 품종에 묶고**, 맞지 않는 상품만 예외로 고친다 | 소분류(예: 우유류)는 품종과 거의 1:1이다 |
| 9 | 새 출처: ~~15109061 지자체 물가조사(MVP 후보), 15109062 유통단계별 가격(MVP 이후 후보)~~ → **둘 다 제외** (2026-10-19 실측: 15109061은 2022-12-30, 15109062는 2016-12-31에서 데이터가 멈춤). 나머지는 리서치 문서에만 | 판정에는 지금 갱신되는 데이터가 필요하다 |

## 다른 단계로 넘기는 것

| 무엇 | 단계 |
|---|---|
| 상품→품종 매핑 세부, 예외 목록 | P3 (`p3-variety-catalog`), p2/06 제조사 코드 결정과 함께 |
| 평소가 계산식, 판정 띠의 폭 | P5 |
| 원본 파일의 저장 위치(레포 안 / 별도 저장소), DB | P4/02, P6 |
| 검색 결과 화면 디자인 | P5, P8 (이 묶음의 06이 입력) |
