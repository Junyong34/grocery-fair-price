# 04. 참가격 정기 수집 (원본 파일 저장)

Status: ready-for-agent
Type: task
Blocked by: 계획·조사 완료 (개발 단계에서 시작)

## 목적

참가격 API는 2026-06-12 이후만 주고, 그 범위가 계속 유지된다는 보장이 없다. 상품 차트에 쓸 이력을 오픈 전부터 원본 그대로 쌓는다. spec.md 결정 5, 6.

## 할 일

- [ ] 조사일 판별: 금요일마다 호출해 빈 `<result/>`가 아닌 날을 조사일로 본다.
- [ ] 받을 범위: 식품 상품 전체 × 전 점포. 상품별 호출(`goodId`, 약 114KB)과 점포별 호출(`entpId`, 약 100KB) 중 호출 수가 적은 쪽을 고른다. 호출 한도 2,000건/일 안에 들어가는지 계산한다.
- [ ] 받는 때: 조사일 다음 날, 그다음 주 월요일. 두 번째에 행 수가 늘었으면 덮어쓴다(10-09 등록 지연 사례).
- [ ] 06-12부터 지금까지 빠진 조사일을 한 번에 채운다.
- [ ] 저장 형식: 조사일·호출 단위별 원본 XML. 경로 규칙과 용량 추정. 레포에 둘지 별도 저장소에 둘지는 용량을 보고 정한다(P4/02).
- [ ] GitHub Actions 일정, 실패 알림
- [ ] `.env` 키가 커밋되지 않는지 확인 (`scripts/check-no-secrets.sh`)

## 완료 기준

- 06-12 이후 모든 조사일의 원본이 저장돼 있다.
- 다음 조사일에 사람 손 없이 저장된다.
