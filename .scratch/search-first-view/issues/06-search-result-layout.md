# 06. 검색 결과 화면 구성안

Status: wontfix (price-screens로 대체됨)
Type: grilling

## 목적

spec.md 결정 1~3, 7, 10을 화면 하나로 묶은 구성안을 만들고 사용자에게 확인받는다. 로드맵 ③ 화면 콘텐츠 설계의 중심 이슈다.

## 정할 것

- 품종 결과와 상품 목록의 경계: 상품이 몇 개부터 접는지, 정렬 기준(100g당 판매가 등)
- 판정 영역에 시세·평소가·차이(%)를 어떻게 함께 보여 줄지
- 차트 두 종류(품종 시세 선 + 평소가 띠, 상품 평균 선 + 최저~최고 띠)를 한 화면에 둘지, 탭으로 나눌지
- 펼쳐 보기: 업태별 최저·최고, 판매처 2단 평균, 할인 표시, 지도
- 업태별 가격 추이: 참가격 상품(대형마트·백화점·슈퍼·편의점)과 KAMIS 전통시장 대 대형유통을 한 차트에 둘지
- 점포 데이터가 없는 품종(배추·당근 등)의 화면 (`p3-variety-catalog/02` 결과)
- 판정 3색과 차트 색 토큰 (색 + 아이콘 + 문구, 명도 대비)
- 지역을 바꾸는 위치
- 상품을 검색했을 때(예: "신라면") 품종 결과로 올라갈지, 상품 결과를 먼저 보여 줄지
