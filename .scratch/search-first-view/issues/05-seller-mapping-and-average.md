## 목적

참가격 상품의 업태별·전체 평균을 정부 화면과 같은 값으로 낸다. spec.md 결정 4. 계산 방식은 [gov-price-sites.md](../../../grocery-price/docs/10-research/gov-price-sites.md) 1장.

## 할 일

- [x] 점포→판매처 매핑표 초안: 참가격 점포 630곳의 `entpName`을 판매처(이마트, 농협, 롯데슈퍼, GS더프레시, CU 등)로 나눈다. 이름으로 안 나뉘는 점포는 따로 표시한다.
- [x] 매핑표 위치: pipeline.md 3-2 `store_seller` (운영자가 관리, 유효 기간 있음)에 맞춘다. 집계는 조사일이 속한 기간의 판매처로 센다.
- [x] 순수 함수와 vitest 테스트를 먼저 쓴다. → 순수 함수 대신 DB 계산(`recomputeProductSummary`)과 DB 테스트로 했다
  - 업태 평균 = 업태 안 판매처별 평균의 평균
  - 전체 평균 = 데이터가 있는 업태 평균의 평균
  - 반올림 규칙 (1,421.5 → 1,422)
  - 테스트 데이터: 2026-09-25 `goodId=1000` 샘플. 기대값 대형마트 1,240, 슈퍼마켓 1,346, 전체 1,422
- [ ] 다른 상품 2~3개, 다른 조사일 하나로 정부 화면과 다시 맞춰 본다. 판매처를 나누는 기준이 맞는지 확인한다.
- [ ] "1개월전"이 몇 번째 이전 조사일인지 확인한다 (08-28 추정).

- `pnpm test`가 통과한다.
