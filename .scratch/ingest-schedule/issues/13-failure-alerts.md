## Question

키 오류는 즉시, 같은 출처 2회 연속 실패는 사람에게 알린다 (5-3). 알림은 GitHub 이슈 자동 생성이고 같은 원인은 하나로 묶는다.

## 할 일

- [ ] 07의 종료 코드·`ingest_run.error_code`로 알림 종류를 고른다: 키 오류 → 즉시, 그 외 실패 → 직전 실행도 실패였을 때

- [ ] 워크플로 권한 `issues: write`를 알림 단계에만
- [ ] 이슈 본문에 키·접속 주소·원본 응답 본문을 넣지 않는다
- [ ] `workflow_dispatch`로 일부러 실패시켜(잘못된 날짜, 빈 키) 이슈 생성·댓글 묶기를 확인

## 완료 기준

- 키 오류와 2회 연속 실패 각각에서 이슈가 하나 생기고, 같은 원인이 다시 나면 댓글로 붙는다.
