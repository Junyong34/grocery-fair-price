## 1. 분석 범위와 읽는 방법

첨부 이미지에 적힌 음식 이름과 O·X 관계를 전사하고, 같은 조합의 중복·충돌 여부를 확인한 문서다. 분석일은 2026년 11월 7일이다.

- O: 원본 표에서 궁합이 잘 맞는다고 표시한 조합.
- X: 원본 표에서 궁합이 잘 맞지 않는다고 표시한 조합.
- `기재 없음`: 해당 칸이 비어 있다. 궁합이 좋거나 나쁘다는 뜻으로 해석하지 않는다.
- 청록색 밑줄·배경 표시: 이미지에 있지만 의미를 설명하는 범례가 없다. 별도의 궁합 등급으로 해석하지 않는다.

이 문서의 O·X는 **이미지에 적힌 주장**이다. 이미지에는 판단 이유, 참고 문헌, 조리법, 섭취량이 없다. 1~5절은 원본 분석과 이름 정리이며, 두 충돌 조합에 대한 외부 자료 검토는 6절에 기록했다. 따라서 X를 섭취 금지나 위험 판정으로 바꾸지 않는다.

## 3. 표 안에서 확인되는 충돌

### 3.1 우유 항목의 두 조합이 O와 X에 동시에 있다

| 조합          | O 표기 위치                              | X 표기 위치        | 분석 결과                                         |
| ------------- | ---------------------------------------- | ------------------ | ------------------------------------------------- |
| 우유 + 고구마 | 우유 항목의 O 목록                       | 우유 항목의 X 목록 | 같은 항목 안에서 충돌                             |
| 우유 + 시금치 | 우유 항목의 O 목록, 시금치 항목의 O 목록 | 우유 항목의 X 목록 | 같은 항목 안에서 충돌하며, 반대쪽 항목도 O로 표기 |

두 조합은 원본 표만으로 O 또는 X를 확정할 수 없다. 전사 표에서는 양쪽 기록을 모두 보존했다. 검색이나 추천 자료로 옮긴다면 두 조합의 상태는 `원본 표기 충돌`로 두어야 한다.

### 3.2 한쪽에만 적힌 관계는 충돌이 아니다

이 표는 모든 음식 조합을 빠짐없이 보여 주는 행렬이 아니다. 기준 음식마다 상대 음식의 일부를 나열한 목록이다.

| 조합            | 확인되는 표기       | 반대쪽 항목                    | 해석                                         |
| --------------- | ------------------- | ------------------------------ | -------------------------------------------- |
| 감자 + 사과     | 감자 항목에서 X     | 사과 항목에 감자 기재 없음     | X 기록 1건. 반대쪽의 빈칸은 반박 근거가 아님 |
| 블루베리 + 우유 | 블루베리 항목에서 X | 우유 항목에 블루베리 기재 없음 | X 기록 1건                                   |
| 두부 + 치즈     | 두부 항목에서 X     | 치즈 항목에 두부 기재 없음     | X 기록 1건                                   |
| 배추 + 무       | 배추 항목에서 O     | 무는 독립된 기준 항목이 없음   | O 기록 1건                                   |

궁합을 서로 대등한 관계로 다루더라도, 원본 전사 단계에서는 어느 항목에 적힌 정보인지 남겨야 한다. `A 항목에서 B가 빠졌다`는 사실을 `A와 B는 궁합이 나쁘다`로 바꿀 수 없다.

### 3.3 양쪽에서 같은 기호로 반복되는 예

| 기호 | 조합            | 확인 위치                |
| ---- | --------------- | ------------------------ |
| O    | 감자 + 고구마   | 감자 항목, 고구마 항목   |
| O    | 감자 + 애호박   | 감자 항목, 애호박 항목   |
| O    | 당근 + 양파     | 당근 항목, 양파 항목     |
| O    | 당근 + 시금치   | 당근 항목, 시금치 항목   |
| O    | 고구마 + 사과   | 고구마 항목, 사과 항목   |
| O    | 두부 + 미역     | 두부 항목, 미역 항목     |
| X    | 감자 + 바나나   | 감자 항목, 바나나 항목   |
| X    | 고구마 + 소고기 | 고구마 항목, 소고기 항목 |
| X    | 당근 + 양배추   | 당근 항목, 양배추 항목   |
| X    | 당근 + 오이     | 당근 항목, 오이 항목     |
| X    | 시금치 + 멸치   | 시금치 항목, 멸치 항목   |
| X    | 시금치 + 두부   | 시금치 항목, 두부 항목   |
| X    | 콩 + 치즈       | 콩 항목, 치즈 항목       |

위 표는 반복 표기의 예시다. 같은 조합이 두 번 적혀 있어도 별개의 연구 근거가 두 개 있다는 뜻은 아니다.

## 4. 음식 이름과 범위 정리

이름만 다른 경우와, 음식의 종류·부위·가공 형태가 다른 경우를 구분한다. 이름을 통합해도 원본의 O·X를 검증한 것으로 보지는 않는다.

### 4.1 확정한 이름 통합

| 원문 표현   | 대표 이름 | 처리                                                                      |
| ----------- | --------- | ------------------------------------------------------------------------- |
| 계란 / 달걀 | 계란      | 같은 음식의 별칭으로 통합. 오이 + 달걀과 계란 + 오이는 같은 조합으로 집계 |

계란·달걀을 서로 다른 음식처럼 다룬 기존 분류는 수정했다. 다만 `달걀노른자`의 관계를 계란 전체로 확대하지 않는다.

### 4.2 추가로 적용한 이름 통일

사용자 요청에 따라 아래 이름을 전체 목록과 집계에 적용했다. 원본의 표현과 판독 메모는 이 표에 남긴다.

| 원문 표현     | 대표 이름 | 처리 및 원본 메모                                                         |
| ------------- | --------- | ------------------------------------------------------------------------- |
| 완두 / 완두콩 | 완두콩    | 식용 콩알을 가리키는 이름으로 통합. 원본에는 콩알·꼬투리 범위 설명이 없음 |
| 메론          | 멜론      | 대표 표기 통일. 원문은 메론                                               |
| 샐러리        | 셀러리    | 대표 표기 통일. 원본 첫 음절의 모음은 판독이 불확실하다는 메모 유지       |

### 4.3 범위가 달라 별도로 유지할 항목

| 표현                      | 처리                                                 | 이유                                                                           |
| ------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------ |
| 계란 / 달걀노른자         | 별도 유지                                            | 전체와 부위의 차이. 노른자에 적힌 관계를 계란 전체에 자동 적용하지 않음        |
| 브로콜리 / 콜리플라워     | 서로 다른 음식으로 구분하되, 원본의 묶인 항목은 유지 | 원본은 한 항목으로 묶었지만 두 음식의 관계를 각각 확인한 것은 아님             |
| 게 / 게살                 | 원문 구분 유지                                       | 게 전체와 살 부위의 범위가 다름. 게에 적힌 관계를 게살로 옮기는 것은 추가 해석 |
| 호박 / 단호박 / 애호박    | 별도 유지                                            | 호박이라는 이름만으로 단호박이나 애호박을 특정할 수 없음                       |
| 콩 / 두부 / 두유 / 콩나물 | 별도 유지                                            | 원료가 관련되어도 가공·발아 형태가 다름                                        |
| 흰살생선 / 조개           | 넓은 범위의 이름으로 유지                            | 개별 품종이 특정되지 않았으므로 각각의 품종에 관계를 일괄 적용하지 않음        |

### 4.4 뜻을 확인해야 하는 항목

| 원문 표현 | 등장 위치            | 남은 확인 사항                                                                        |
| --------- | -------------------- | ------------------------------------------------------------------------------------- |
| 비타민    | 소고기·두부의 O 목록 | 특정 채소 이름인지 영양소인지 이미지에는 설명이 없음. 채소라는 가정으로 확정하지 않음 |

## 5. 활용 시 판단

이 이미지는 음식별 O·X 목록을 찾아보는 원자료로 정리할 수 있다. 다만 우유 항목의 두 충돌과 근거 부재 때문에, 그대로 검증된 궁합 판정 자료로 사용하기에는 부족하다.

표에 없는 조합은 `정보 없음`으로 두고, 충돌한 두 조합은 `원본 표기 충돌`로 구분한다. O·X와 함께 원문 위치를 남기면 이후 근거를 확인하거나 오기를 수정할 때 출처를 추적할 수 있다.

이미지 하단의 이름에 `이유식`이 들어가지만, 이미지에는 대상 월령, 알레르기, 조리 형태에 관한 설명이 없다. 이 표에서 이유식 적합 여부를 도출하지 않는다.

추가 검증 없이 확정할 수 있는 것은 음식 이름, O·X 표기, 표 안의 중복과 충돌이다. 각 조합이 실제로 왜 잘 맞거나 맞지 않는지는 이 이미지로 알 수 없다.

## 6. 이유식·영유아 식사 목적의 충돌 조합 조사

2026년 11월 7일, 공공 보건기관과 영양 자료를 확인했다. 2절의 O·X는 원본대로 두고, 아래에 조사 결과를 구분했다. 여기서 우유는 일반 소젖 우유이며 모유·영아용 분유와 구분한다.

### 6.1 권장 표기

| 조합          | 조사 결과                                                                                                                              | 정리할 표기                                                           |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 우유 + 고구마 | NHS가 생후 6개월 이상 고구마·당근 퓌레에 소량의 전지우유를 섞는 방법을 제시한다                                                        | 함께 사용 가능, 월령·우유 사용 형태 조건 명시                         |
| 우유 + 시금치 | NHS 기관이 제공하는 영유아 조리 자료에 시금치 소스와 전지우유를 섞는 예가 있다. 다만 시금치 자체의 영아 섭취 지침은 국가별 차이가 있다 | 우유와의 조합을 이유로 X 처리하지 않음. 시금치 월령·양 지침 별도 확인 |

**두 조합 모두 '서로 상극이라 함께 주면 안 된다'는 X 표기를 뒷받침하는 근거는 확인하지 못했다.** 다만 조리 자료에 함께 사용된다는 사실이 특별한 영양 상승효과를 입증하지는 않는다. 따라서 원래의 O가 '궁합이 특별히 좋다'는 뜻이라면 O 역시 확정하지 않고, `함께 사용 가능`이라는 표현으로 바꾸는 편이 정확하다.

### 6.2 우유 + 고구마의 직접 근거

NHS의 `Root vegetable mash`는 생후 6개월 이상을 대상으로 고구마와 당근을 익혀 으깨는 이유식이다. 농도가 너무 되면 소량의 전지우유 또는 아기가 평소 먹는 수유용 유즙을 넣도록 설명한다. 고구마와 우유의 병용을 허용하는 직접적인 조리 예다. [NHS 고구마·당근 퓌레](https://www.nhs.uk/best-start-in-life/baby/recipes-and-meal-ideas/root-vegetable-mash/)

이 자료로 확인할 수 있는 것은 '소량의 우유를 섞어 이유식으로 사용할 수 있다'는 범위다. 영양소 흡수를 특별히 높이거나 모든 아기의 소화를 개선한다는 효과는 확인되지 않았다.

### 6.3 우유 + 시금치의 직접 근거와 옥살산 해석

NHS 기관 사이트가 제공하는 `Eating well: 6 months to 2 years – For South Asian children`의 인쇄 쪽수 34쪽에는 시금치 소스의 농도를 모유·전지우유·전지 요구르트로 조절하는 방법이 나온다. 7~9개월 및 10~12개월 제공 예에도 우유가 포함된다. 이 자료는 First Steps Nutrition Trust가 NEON 프로그램과 협력해 작성한 영유아 조리 자료이며, 우유·시금치 조합의 임상시험은 아니다. [영유아 조리 자료 34쪽](https://www.justonenorfolk.nhs.uk/media/cublqwzg/eating-well-6-months-to-2-years-for-south-asian-children-neon-recipe-book-final-version-web-compressed.pdf#page=34)

미국 NIH 자료는 시금치의 옥살산이 칼슘과 불용성 염을 만들어 칼슘 흡수에 영향을 줄 수 있다고 설명한다. 같은 자료는 고구마도 옥살산 함량이 높은 음식에 포함하며, 다양한 식사를 할 때 이러한 상호작용의 영양학적 영향은 거의 없거나 없을 수 있다고 설명한다. 이 기전만으로 두 조합을 영유아의 섭취 금기라고 판단할 수는 없다. [NIH 칼슘 자료, Food 절](https://ods.od.nih.gov/factsheets/Calcium-HealthProfessional/)

특히 시금치 자체 칼슘의 낮은 흡수율을 '시금치와 함께 먹으면 우유의 칼슘도 같은 비율로 흡수되지 않는다'는 수치로 바꾸면 안 된다. 이 조사에서 두 조합을 먹은 영유아의 장기 성장이나 임상 결과를 직접 비교하는 근거까지 확보한 것은 아니다.

### 6.4 영아에게 적용할 때의 조건

NHS는 일반 우유를 생후 약 6개월부터 음식에 섞거나 조리에 사용할 수 있지만, 주된 음료로 주는 것은 생후 12개월부터라고 구분한다. 따라서 돌 전 아기에게 고구마 우유 음료를 만들어 수유를 대체하는 것으로 해석하면 안 된다. 비살균 우유는 어린아이에게 제공하지 않도록 안내한다. [NHS 아기 음료·우유 지침](https://www.nhs.uk/baby/weaning-and-feeding/drinks-and-cups-for-babies-and-young-children/)

시금치의 월령 기준에는 국가별 차이가 있다. 위 영국 자료는 영아 조리에 시금치를 사용하지만, 스페인 보건부는 질산염과 관련한 메트헤모글로빈혈증 위험 때문에 첫돌 전 시금치를 피하도록 안내한다. 이는 우유와 함께 먹어서 생기는 문제라는 뜻이 아니다. 따라서 영아용 표에는 `우유와 조합 가능`과 `시금치 자체의 월령·섭취량 조건`을 분리해야 한다. [스페인 보건부 영유아 제한 식품 안내](https://estilosdevidasaludable.sanidad.gob.es/alimentacionSaludable/lactancia/alimentacionComplementaria/evitar/home.htm)

위 결론은 한국의 개별 아기에게 월령별 식단을 처방하는 내용이 아니다. 특히 우유 알레르기가 있거나 의심되는 아기는 조합표의 O 표시와 별개로 진료 지침을 따라야 한다. NHS도 우유 알레르기·불내성이 있는 경우 적절한 대체 식품을 의료진과 상의하도록 안내한다. [NHS 영유아 유제품 안내](https://www.nhs.uk/baby/weaning-and-feeding/what-to-feed-young-children/)
