# 이유식 재료 궁합 콘텐츠 시안

Status: needs-triage

## 확정한 방향

- 사용자가 가진 큐브 재료를 골라 참고하는 콘텐츠. 한 끼의 영양·안전 적합성을 판정하지 않는다.
- 영양 특징과 조리 특징을 다룬다. 월령은 선택사항이다.
- 선택 화면과 결과 화면은 별도다. 선택을 보존한 채 돌아가서 바꿀 수 있다.
- 전체 궁합표는 재료 선택 없이 직접 열 수 있는 독립 화면으로 제공한다. 결과 화면에서는 큰 모달로도 열 수 있다. 모달에서 전체 페이지로 이동할 수 있다.
- 결과는 선택한 기준 재료의 O·X 전체 목록을 보여준다. 선택하지 않은 상대 재료도 표시하며, 선택한 상대 재료를 강조한다.
- 표에 없는 관계를 근거 미확인 카드로 나열하지 않는다. 목록이 모든 관계를 포괄하지 않는다는 짧은 설명만 둔다.
- 기존 이미지의 O·X와 조사 결과를 구분한다. 설명은 옆 영역 또는 모달에서 확인한다. 우유 관련 두 충돌 관계를 무조건적인 X로 재사용하지 않는다.
- PDF는 여러 기준 재료를 A4 2~3장에 나눈다. 기존 로컬 어드민에서 생성하는 방식이다. 운영 어드민은 추가하지 않는다.
- 음식 이미지는 기존 파일을 우선 재사용한다. 부족한 이미지는 별도 티켓에 목록과 신규 제작 작업을 남긴다.

## 시안 범위

대화에서 조작 가능한 재료 검색·카테고리·선택·별도 결과·표 필터·설명 모달·인쇄 구성 미리보기를 제공한다. 실제 공개 페이지나 PDF 생성 기능 구현이 아니다. 31개 기준 항목의 목록은 `docs/food-pairing-image-analysis.md`를 읽는다. 월령 선택값은 보존하지만 검증된 월령 데이터가 없으므로 궁합을 자동 재판정하지 않는다.

## 실제 페이지 구현

- `/baby-food`에서 재료·월령을 고르고, `/baby-food/result`에서 원본 O·X 목록과 선택 강조를 확인한다. 선택은 URL에 담고 기준 재료 목록으로 검증한다.
- `/baby-food/pairings`를 직접 열면 기준 재료 31개의 전체표를 렌더링한다. 결과에서 같은 주소로 이동할 때는 인터셉팅 라우트가 3장 모달을 연다.
- 선택 화면과 결과는 noindex, 전체표는 사이트맵과 canonical에 등록한다. 시세 메인에서 전체표로 연결한다.
- 기준·상대 재료에 기존 SVG 48개를 연결했다. 이미지가 없는 재료는 점선 자리와 이름을 표시한다.

## 후속 작업

- 영양·조리 특징 본문과 조합별 근거 추가 검토.
- `issues/01-illustrations.md`의 이미지 범위 검토와 누락 작업.
- PDF 공개 배포가 필요하면 기존 에디션 목록과 다운로드 흐름에 연결한다.

## 전체 궁합표 접근과 SEO 구현 계획

- 공개 주소 `/baby-food/pairings`는 `shared/routes.ts`에 등록했다. 고정 콘텐츠이므로 catch-all `[...slug]`는 필요하지 않다.
- 직접 방문·새로고침·검색 유입은 전체 페이지를 렌더링한다. 전체 31개 기준 항목의 표, O·X 의미, 자료의 한계, 출처와 검토일을 서버 HTML에 제공한다.
- 앱 안 결과 화면에서 링크를 눌렀을 때는 Intercepting Routes와 Parallel Routes를 사용해 같은 콘텐츠를 모달로 열 수 있다. 모달 닫기·뒤로 가기 시 선택 상태를 유지한다. 실제 오버레이는 프로젝트 규칙에 따라 overlay-kit과 디자인 시스템 컴포넌트를 사용한다.
- 전체 페이지와 모달은 같은 재료 표 컴포넌트를 사용한다. 후속 인쇄 기능도 음식 관계와 설명을 공통 데이터에서 읽는다.
- 의미 있는 제목·설명·자기 자신을 가리키는 canonical을 `createMetadata`로 제공한다. `shared/seo/pages.ts`와 사이트맵에 등록하고 공개 내부 링크로 연결한다. 검색엔진의 실제 색인을 보장하는 것은 아니다.
- 개인 선택 결과와 검색 필터별 URL은 별도 색인 대상으로 만들지 않는다. 전체 표의 고정 주소를 검색 유입 대상으로 삼는다.
- 기준·근거·한계 설명은 모달 버튼 뒤에만 숨기지 않고 전체 페이지 본문에도 제공한다. 관계별 상세 설명은 추가로 모달에서 확인할 수 있다.
- 참고한 버전 일치 문서: 설치된 Next.js의 `intercepting-routes.md`, `parallel-routes.md`, `14-metadata-and-og-images.md`. 원본의 O·X를 검증된 의학적 사실로 격상하지 않는다.

## 시안 검증 기록

- 2026-11-08, 별도 미리보기에서 375·1280 너비로 확인했다.
- 재료 검색·선택/해제·결과 이동·선택 보존·선택 행/전체 31행 전환·근거 모달·A4 세 장 구성 미리보기를 확인했다.
- 모바일 가로 넘침 없음, 시안 내 음식 이미지 로드 성공, 브라우저 콘솔 오류 없음.
- 앱 소스 변경이 없는 시안 작업이다. 저장소 전체 검사는 타 작업의 기존 병합 충돌 때문에 실행하지 않았다.
- 영양·조리 특징의 실제 상세 본문과 실제 PDF 생성은 후속 구현 범위다. 인쇄 구성 미리보기는 페이지 분할을 논의하기 위한 축소 시안이다.

### 전체 궁합표 추가 시안 검증

- 직접 전체 화면 진입 시 기준 항목 31행, 당근 검색 시 1행 표시를 확인했다.
- 결과 화면 → 전체표 모달 31행 → 전체 페이지 전환을 확인했다. 재료 선택은 보존한다.
- 375·1280 너비에서 확인했고 모바일 가로 넘침과 콘솔 오류가 없었다. 실제 Next.js 라우팅·SEO 등록은 아직 구현하지 않았다.

## 앱 검증

- 375px·1280px 브라우저에서 선택 → 결과 → 3장 모달, 근거 확인 후 같은 장으로 복귀, 선택·월령을 유지한 재료 변경을 확인했다.
- 전체 궁합표 서버 HTML에서 기준 재료 31개, canonical, 탐색경로 JSON-LD, 출처 링크를 확인했다.
- 사이트맵에 전체표만 포함되고 선택·결과는 noindex를 내는 것을 확인했다.


## 로컬 A4 인쇄

- `/admin`의 새 에디션 종류에서 이유식 궁합표를 고르면 `/admin/baby-food/print`에서 A4 세로 3장을 미리 본다.
- PDF 생성 버튼은 같은 문서를 로컬 Chrome으로 인쇄한다. 용지 넘침, 쪽 수와 용지 크기를 확인한 뒤 브라우저에 내려준다.
- 기준 재료 31개를 O·X 목록 길이에 맞춰 A4 세 장의 9열에 고르게 나눈다. 기준·상대 재료의 이름과 기존 그림 또는 점선 자리를 함께 그린다.
