# 수산·제철 회 콘텐츠 자료

새 수산·회 화면을 기획하기 위한 자료 모음이다. 사용자 첨부 이미지에서 옮긴 월별 설명과 기존 제철 목록의 이름 대응, 이미지 제작용 특징을 Git 관리 경로에 보관한다. `prototypes/`가 없는 새 클론에서도 이 폴더만으로 자료를 읽을 수 있다.

## 문서 구성

| 파일                                             | 내용                                                             |
| ------------------------------------------------ | ---------------------------------------------------------------- |
| [monthly-content.md](monthly-content.md)         | 1~12월의 맛·식감·지역 설명 55개, 계절별 요약 4개                 |
| [species-review.md](species-review.md)           | 48종의 기존 목록 대응, 신규 후보 29종, 불명확한 이름과 확인 자료 |
| [illustration-briefs.md](illustration-briefs.md) | 신규 후보 29종의 통생선 외형·색·구별점과 9개 요청 필드           |
| [reference.json](reference.json)                 | 첨부에서 전사한 이름·추천 월·설명 원문과 기존 목록 이름의 대응   |

`reference.json`과 월별 문서는 신규 후보만이 아니라 기존 항목도 포함한다. 같은 생선이 여러 달에 나오면 각 달의 설명을 보존한다. 별칭과 목록 이름의 대응을 합친 수는 48종이며, 확정된 생물학적 종 수를 뜻하지 않는다.

## 새 화면을 위한 출발점

> 2026-11-10: 이 자료로 만든 화면이 `/seasonal/sashimi/[month]`(제철 회)다. 정한 내용은 `.scratch/sashimi/spec.md`가 정본이고, 아래 표는 기획 당시의 검토안이다.

사용자가 밝힌 목적은 기존 제철달력과 함께 사용할 새로운 수산·회 콘텐츠 화면이다. 아래 구성은 보유 자료로 검토할 수 있는 안이다.

| 화면에서 볼 정보       | 현재 자료                         | 더 정할 것                                        |
| ---------------------- | --------------------------------- | ------------------------------------------------- |
| 월을 골라 보는 회 목록 | 12개월별 이름과 추천 월           | 첫 진입 월과 월 이동 방식                         |
| 생선별 맛·식감 설명    | 월별 원문 55개                    | 게시용 문장, 반복 표현 정리, 설명의 근거          |
| 생선 이름과 관련 정보  | 첨부 이름과 기존 목록 이름의 대응 | 표시 이름, 별칭 검색, 상세 정보의 범위            |
| 이미지                 | 통생선 요청 초안 29종             | 통생선 일러스트 또는 회 접시 사진, 실제 제작 범위 |

월별 목록에서 생선을 고르고 맛·식감을 읽는 흐름을 먼저 검토할 수 있다. 기존 제철달력의 원물 그림과 새 회 콘텐츠의 사진·설명을 어떻게 연결할지는 별도 화면 기획에서 정한다.

## 원문과 검증 상태

출처는 사용자가 2026-11-02에 첨부한 "월별 제철 회 총정리" 이미지 3장이다. 원본 작성자와 제철 판단 근거는 확인되지 않았다. `monthlyContent[].foods[].description`은 이미지에서 옮긴 원문이고, 완성된 게시 문구는 아니다.

첨부의 추천 월은 출처로 확인한 제철 범위가 아니다. 그래도 2026-11-02에 그림이 있는 32종을 이 추천 월로 앱 제철 목록에 올렸고, 그때 그림이 없어 빠졌던 학꽁치도 그림을 그린 뒤 2월로 올려 모두 33종이다(앱 품종 240개). 미검증·사용자 자료 후보 29종(학꽁치 포함)은 추천 월을 그대로 썼고, 해수부 후보 4종(복어·홍어·멸치·감성돔)은 기존 선정 월에 추천 월을 더했다. 앱에서 이 품종은 모두 `core: false`다. 새 횟감 29종(학꽁치 포함)은 친숙도 3등급이라 대표 품종을 고를 때 뒤로 간다. 근거를 확인하면 품종 원본 `packages/seasonal/src/data/food-registry.json`의 달과 근거(출처, 확인일, 사유)를 고친다. 특히 붕장어와 바다장어, 참홍어와 기존 홍어의 대응에는 [검토 기록](species-review.md)의 조건이 붙는다.

회로 소개할 어종과 제철 범위가 확정되면 근거와 확인 날짜, 지역, 자연산·양식 조건을 기록한다. 확인된 항목부터 게시용 문구를 작성한다. 문서 원문을 그대로 런타임 데이터에 연결하거나 가정한 종을 확정 정보로 표시하지 않는다.

## 구조화 자료의 필드

| 경로                                   | 의미                                                                              |
| -------------------------------------- | --------------------------------------------------------------------------------- |
| `source`, `images`                     | 첨부 자료명, 첨부 날짜와 이미지 파일명. 이미지 바이너리는 이 폴더에 포함하지 않음 |
| `status`, `contentStatus`              | 추천 월과 설명 원문의 검증·편집 상태                                              |
| `foods[]`                              | 중복 월을 합친 48개 목록 대응 항목                                                |
| `foods[].name`                         | 기존 제철 목록에 대응시킨 이름. 서비스의 확정 id가 아님                           |
| `foods[].sourceNames`                  | 첨부에 적힌 이름                                                                  |
| `foods[].months`                       | 첨부의 추천 월. 그 밖의 달은 자료에서 추천하지 않았다는 뜻이며 비제철 확정이 아님 |
| `foods[].note`                         | 이름 대응의 조건과 추가 확인 사항                                                 |
| `monthlyContent[]`                     | 12개월의 제목, 이미지 파일명과 생선별 설명                                        |
| `monthlyContent[].foods[].sourceName`  | 해당 월의 첨부 이름                                                               |
| `monthlyContent[].foods[].name`        | `foods[].name`과 대응하는 이름                                                    |
| `monthlyContent[].foods[].description` | 해당 월의 맛·식감·지역 설명 원문                                                  |
| `seasonalSummary[]`                    | 첨부의 계절별 월 구분과 요약 원문 4개                                             |

## 관리 범위

이 폴더는 콘텐츠 조사·기획용 문서다. 앱의 확정 제철 데이터는 `packages/seasonal`에서 관리한다. 가격 데이터는 별도 가격 도메인의 자료를 쓴다. 앱 제철 목록에 올린 33종은 위 [원문과 검증 상태](#원문과-검증-상태)에 적었다. 이 폴더의 문서는 앱 데이터의 원천이 아니며, 목록은 `prototypes/seasonal-food`의 생성기로 다시 만든다.

콘텐츠 자료의 관리 위치는 이 폴더다. 로컬 프로토타입에 남은 자료는 이전 작업용 사본이며 새 화면의 원천으로 사용하지 않는다.

전사 오류를 수정하면 `reference.json`과 월별 문서를 함께 고친다. 원문을 바탕으로 새로 작성한 게시 문구는 원문과 구분해 기록한다. 이미지 요청은 제작 단계에서 외형을 확인하며 갱신한다.
