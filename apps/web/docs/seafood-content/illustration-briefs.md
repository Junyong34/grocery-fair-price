# 제철 회 이미지 제작용 특징

2026-11-02 첨부 자료에서 기존 수산 목록에 빠졌던 29종의 최초 이미지 요청 초안 보관본이다. 이후 그림 제작 완료 여부와 분리해 콘텐츠 특징을 보존한다. [월별 맛·식감 설명](monthly-content.md)은 별도 문서에 있다.

현재 요청은 기존 제철 일러스트 시리즈에 맞춘 통생선 구도다. 새 회 화면의 사진이나 회 접시 구도는 아직 정하지 않았다. 첨부의 회 접시 사진만으로 통생선의 외형을 확인했다고 해석하지 않는다. 각 블록의 형태·비율·색은 작도 전에 실물과 대조할 초안이다.

## 요청서 항목

| 항목                | 의미                                               |
| ------------------- | -------------------------------------------------- |
| 품목                | 요청 템플릿의 기존 필드명. 그릴 구체적인 품종 이름 |
| 보여줄 모습         | 통생선의 수, 상태와 구도                           |
| 꼭 보여야 할 특징   | 식별에 필요한 특징 3개                             |
| 헷갈리면 안 되는 것 | 비슷한 어종과 구별할 부위                          |
| 색                  | 부위별 체색 초안                                   |
| 크기감              | 작게, 중간, 크게                                   |
| 디테일              | 보통 또는 많이, 특히 살릴 부위                     |
| 참고 이미지         | 실물 참고 사진 지정 여부. 현재 전부 없음           |
| 제철                | 첨부의 추천 월. 제철 범위 미검증                   |

이름 대응과 종을 확인할 항목은 [어종 대조·검토 기록](species-review.md)에 있다. `†`는 종이나 제철 범위의 추가 확인이 필요한 후보라는 뜻이다. 용어는 저장소의 [GLOSSARY](../../../../grocery-price/GLOSSARY.md)를 따른다.

### 줄가자미†

```text
품목: 줄가자미
보여줄 모습: 눈이 모인 면을 위에서 본 통생선 한 마리, 몸 전체와 거친 표면을 함께 보인다
꼭 보여야 할 특징: 오른쪽에 모인 두 눈 · 넓은 타원형의 납작한 몸 · 눈 있는 면 전반에 흩어진 단단한 돌기
헷갈리면 안 되는 것: 돌가자미: 돌가자미의 돌기는 줄을 이루지만 줄가자미는 눈 있는 면 전반이 거칠다; 광어: 눈 방향과 큰 입의 비율을 구분한다
색: 눈 있는 면은 회갈색, 배 쪽은 옅은 자줏빛을 띤 흰색, 돌기는 밝은 회갈색
크기감: 중간
디테일: 많이 / 거친 돌기의 분포를 살리고 이름 때문에 줄무늬를 임의로 넣지 않는다
```
