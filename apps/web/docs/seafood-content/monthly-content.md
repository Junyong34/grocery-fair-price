# 월별 제철 회 콘텐츠 소재

사용자가 2026-11-02에 첨부한 「월별 제철 회 총정리」 이미지 3장에 있는 맛·식감·지역 설명을 보관한다. **기존 항목을 포함한 48종, 월별 설명 55개**이며, 같은 생선도 월별 문구를 따로 남겼다.

아래 설명은 이미지에서 옮긴 원문으로, 제철·맛의 독립 검증이나 게시용 편집을 마친 문구는 아니다. 이미지 제작용 외형 특징은 [수산 요청서](illustration-briefs.md)에 따로 있다.

- 구조화 원천: [reference.json](reference.json)의 `monthlyContent`와 `seasonalSummary`.
- `sourceName`은 첨부에 적힌 이름, `name`은 기존 제철 목록에 대응시킨 이름, `description`은 첨부의 설명 원문이다.
- 이 문서는 수작업 콘텐츠 문서다. 전사 오류를 고치면 `reference.json`도 함께 고친다. 검증·편집한 새 콘텐츠는 이 원문과 구분해 작성한다.
