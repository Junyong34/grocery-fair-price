# 월별 회 이미지와 수산 목록 대조 (2026-11-02)

사용자 첨부 「월별 제철 회 총정리」 3장의 55개 월별 항목을 전사했다. 중복 월을 합치면 48종이고, 기존 66종의 수산 목록에 대응하는 19종을 제외한 **29종을 추가 후보**로 넣었다. 이는 2026-11-02 로컬 작업 목록 기준이며, 현재 앱에서 노출하는 품종 수와는 다르다.

- 원천: [reference.json](reference.json). 1~4월 `1000082558.jpg`, 5~8월 `1000082559.jpg`, 9~12월 `1000082561.jpg`.
- 기존 품종의 월·검증 상태는 유지한다. 아래 월은 첨부에서 읽은 추천 월이며, 범위를 넓혀 추정하지 않는다.
- 첨부는 작성자·판단 기준·원산지·자연산과 양식 조건이 명시되지 않았다. 최초 목록 추가 때 새 품종을 `tier: reference`, `conditional: true`로 분류했다. 이 분류는 첨부의 검증 상태를 뜻한다.
- 최초 후보 추가 때는 앱의 확정 목록에 자동 노출하지 않았다. 이후 2026-11-02에 그림이 있는 32종을 추천 월로 앱에 올렸고, 학꽁치도 그림을 그린 뒤 올려 모두 33종이다([README](README.md#원문과-검증-상태)). 아래 표의 처리는 최초 대조 때의 기록이다.
- [이미지 요청서](illustration-briefs.md)에는 같은 29종을 통생선 구도로 추가했다. 형태 설명은 제작용 초안이며 실물 사진을 직접 열어 관찰한 결과가 아니다. 실제 작도 전 종·성장 단계·체색을 확인한다.

## 이름과 기존 그림의 주의점

기존 그림과의 대응은 이전 작업에서 확인한 기록이다. 이 문서를 읽는 데 원본 그림 폴더는 필요하지 않다. 재작도할 때는 실제 그림과 명세를 다시 대조한다.

- **홍어**: 첨부의 참홍어는 기존 홍어 그림(skate)이 명시한 참홍어(Beringraja pulchra)에 대응한다. 처음에는 기존 선정 월 4월에 첨부의 1월을 합치지 않았으나, 2026-11-02 앱 반영 때 1·4월로 합쳤다. 간재미와는 다른 종이다.
- **간재미**: 표준명 홍어(Okamejei kenojei)를 대상으로 한다. 기존 홍어 항목의 그림은 참홍어이므로 그림을 공유하지 않는다. 이름 키에 홍어를 넣으면 기존 참홍어 그림과 오매칭되어 간재미만 키로 쓴다.
- **숭어**: 첨부의 보리숭어는 숭어의 별칭으로 처리한다. 가숭어와는 다른 종이다. 기존 mullet 그림의 노란 눈 설명은 가숭어와 혼동 가능성이 있어 재작도 전에 검토한다.
- **바다장어**: 첨부의 붕장어는 기존 바다장어의 흰 점 한 줄·둥근 주둥이 표현에 대응시켜 중복 추가하지 않았다. 바다장어는 총칭이고 원본 NOTES에는 종 미확정이라고 되어 있으므로, 작도 재검토 시 붕장어(Conger myriaster) 여부를 확인한다. 갯장어는 별도 후보다.
- **봄 도다리(문치가자미)**: 첨부의 도다리는 기존 봄 도다리(문치가자미)에 대응시켰다. 표준명 도다리·강도다리와 혼동하지 않으며 기존 제철 범위는 유지한다.
- **불볼락(열기)**: 첨부의 열기는 불볼락(Sebastes thompsoni)으로 대상을 구체화했다. 볼락·조피볼락과 별도 품종이다.
- **망둥어**: 여러 망둑어류를 가리키는 이름이다. 이미지 요청서는 문절망둑을 대상으로 가정한 초안이며 첨부에서 종은 확인되지 않는다. 종과 11월 제철 근거를 확인한 뒤 작도한다.
- **쌍동가리**: 쌍동가리(Parapercis sexfasciata)를 대상으로 한다. 열쌍동가리·흰동가리와 혼동하지 않는다.
- **자바리**: 자바리(Epinephelus bruneus)를 대상으로 한다. 제주 방언 다금바리와 표준명 다금바리(Niphon spinosus)는 구분한다.

## 남은 확인

- `망둥어`: 첨부만으로는 문절망둑인지 풀망둑인지 알 수 없다. 요청서는 문절망둑 가정임을 명시했다.
- 기존 `숭어` 그림은 노란 홍채를 특징으로 적어 가숭어와 혼동될 수 있다. 이번에 기존 SVG를 바꾸거나 가숭어 그림으로 재사용하지 않았다.
- 기존 `홍어` 그림은 이름은 홍어지만 명세의 대상은 참홍어다. 간재미에는 그 그림을 연결하지 않는다.
- 기존 `바다장어` 그림은 붕장어와 닮은 흰 점 한 줄·둥근 주둥이를 갖지만 NOTES는 종을 미확정으로 남겼다. 이번 대응은 목록 중복을 줄이기 위한 잠정 대응이며 생물학적 동의어 확정이 아니다.
