# 01. 제품 컨셉

## 1. 문제 정의

- 장을 가끔 보는 사람(신혼부부, 자취생, 장보기 초보)은 식자재의 **적정 가격 감각이 없다.**
- 가격은 행사, 계절, 날씨(장마·한파), 판매처, 포장 단위에 따라 크게 변한다.
- 가전·의류는 다나와나 네이버쇼핑에서 **특정 모델(SKU)** 을 검색해 비교하면 된다. 하지만 애호박, 두부, 삼겹살 같은 **품목 단위**는 판매처마다 상품명·단위·포장이 달라 직접 비교하기 어렵다.

## 2. 포지셔닝

| 기존 가격비교 | 이 서비스 |
|---|---|
| "어디가 제일 싸?" | **"지금 이 가격 괜찮아?"** |
| 상품(SKU) 단위 | **품목** 단위 (애호박, 삼겹살) |
| 현재 최저가 나열 | **평소가 대비 판정 + 추이** |
| 포장 단위별 가격 | **100g당 단가로 정규화** |
| 온라인 위주 | 오프라인 시세 + 온라인 (단계적) |

경쟁자이자 데이터 원천: 한국소비자원 **참가격**, aT **KAMIS**. 데이터는 좋지만 일반 소비자가 장 보면서 쓸 UX는 아니다. 이 간극이 기회다.

## 3. 메인 기능: 가격 판정

### 3.1 판정 화면 (진열대 앞 3초)

```
[애호박]                         2026-10-08 기준
┌─────────────────────────────────────────┐
│  🟡 보통                                  │
│  평소보다 8% 비싸요                        │
│                                         │
│  최저 1,480 ──●────────── 최고 3,200      │
│        평소 2,050   지금 2,210 (1개)        │
│                                         │
│  💬 장마 이후 호박류 전반 상승 중            │
└─────────────────────────────────────────┘
[내가 본 가격 입력: ____원 / __개 / __g] → 즉시 판정
```

- **1순위는 판정 신호**(싸다 / 보통 / 비싸다), 차트는 근거로 아래에 둔다.
- trolley.co.uk의 **최저 / 평소 / 최고 3점 비교 + 평소 대비 %** 방식을 참고한다 ([content-and-taxonomy.md](../10-research/content-and-taxonomy.md) 5장).
- **사용자가 지금 보는 가격을 입력하면** 그 가격을 판정해 준다. 이 기능이 "진열대 앞" 사용 시나리오의 핵심이다.

### 3.2 판정 기준 (초안)

- **기준가(평소가)**: KAMIS 평년 가격과 최근 N주 중앙값을 결합한다.
- **판정 구간 예시**: 기준가 대비 -10% 이하면 싸다, ±10% 이내면 보통, +10% 이상이면 비싸다. 품목별 변동성(채소는 크고 가공식품은 작다)에 따라 임계값을 다르게 둔다.
- **계절성 반영**: 같은 달의 예년 가격과도 비교한다. 겨울 애호박이 비싼 건 "정상"일 수 있다.

### 3.3 차트

- 기간 탭: 1개월 / 3개월 / 1년 (KAMIS 일별 데이터는 호출당 최대 1년).
- 판매처·업태별 라인: 참가격의 업체 실명 데이터, KAMIS의 대형마트/전통시장 구분.
- 행사 기간은 차트에 음영으로 표시하고, 판정 기준가 계산에서는 제외한다.

## 4. 가격 표시 항목

말씀하신 항목과 데이터 근거를 정리했다.

| 항목 | 설명 | 데이터 근거 |
|---|---|---|
| 판매가 | 표시 가격 | 모든 소스 |
| 행사가 | 할인가, 1+1 여부, 행사 기간 | 참가격: 할인여부·할인기간·1+1 필드 있음 |
| 배송비 포함/미포함 | 온라인몰 전용. 무료배송 기준금액, 멤버십 조건 | 온라인 소스 확보 이후 |
| 수량 · 중량 · 크기 | 1개 / 2입 / 500g / 특·상 등급 | KAMIS 단위·단위크기, 참가격 용량·단위 |
| **100g당 단가** | 비교의 기준값 | 가격표시제 실시요령 별표 2 |
| 원산지 · 등급 | 국산/수입, 한우 1++ 등 | 축평원 등급·원산지 구분 |
| 주의 문구 | "크기 편차가 큰 품목", "수입산 혼재", "행사가라 일시적" 등 | 규칙 기반으로 생성 |
| **신뢰도** | 이 가격을 얼마나 믿을 수 있는지 | 아래 4.1 |
| 출처 · 기준일 | "한국소비자원 참가격, 10/02 조사" | 공공누리 출처표시 의무 |

### 4.1 신뢰도 표시 (초안)

| 요소 | 높음 | 낮음 |
|---|---|---|
| 출처 유형 | 공공 조사 (KAMIS, 참가격, 축평원) | 사용자 제보 1건 |
| 최신성 | 오늘·어제 | 2주 이상 경과 |
| 표본 수 | 여러 지역·판매점 평균 | 단일 판매점 |
| 일관성 | 다른 소스와 비슷함 | 이상치 |

화면에는 "신뢰도 ●●●○ · 공공조사 22개 도시 평균 · 어제" 정도로 짧게 보여준다.

## 5. 유입 콘텐츠

| 콘텐츠 | 내용 | 데이터 |
|---|---|---|
| **오늘 싼 식자재** | 평년·지난주 대비 하락률 상위 품목 | KAMIS (매일) |
| **제철 식재료** | 월별 제철 품목 + 지금 가격 판정 | 농정원 제철 농식품(51건), 농진청 이달의 음식 |
| **싼 재료로 만드는 요리** | 오늘 싼 품목이 들어간 레시피 추천 | 식약처 레시피 1,156건, 농정원 레시피 재료정보 API |
| **자취생 콘텐츠** | 1인분 레시피, 소용량 단가 비교, 편의점 vs 마트 가격 | 참가격에 편의점(CU, GS25, 세븐일레븐, 이마트24) 가격 포함 |
| **가격 알림** (재방문 장치) | 장보기 리스트 품목이 "싸다"가 되면 알림 | 판정 결과 |

"장을 가끔 보는 사람"이 타깃이라 사용 빈도가 낮다. 알림과 제철·오늘 싼 식자재 콘텐츠를 재방문 장치로 쓴다.

## 6. 카테고리 분류 방향

- **2층 구조**: 사용자에게 보이는 분류(채소 > 열매채소 > 애호박)와 데이터 원천 코드(KAMIS 200-224, 참가격 상품 ID)를 분리하고 매핑 테이블로 연결한다.
- 출발점은 KAMIS 부류(식량작물·채소·특용·과일·축산·수산)와 참가격 분류(정육·난류, 채소, 수산가공품 등)를 합친 자체 분류다.
- 상세는 [content-and-taxonomy.md](../10-research/content-and-taxonomy.md)와 도메인 모델링 단계에서 정한다.
