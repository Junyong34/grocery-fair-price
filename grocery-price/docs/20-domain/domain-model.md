# 도메인 모델

용어 정의는 [GLOSSARY.md](../../GLOSSARY.md)에 있다. 이 문서는 개념 사이의 관계, 규칙, 시나리오, 결정 이력을 담는다.

## 1. 분류 계층

```
카테고리      채소                     정육·계란
  └ 품목      호박                     소고기
      └ 품종  애호박 · 쥬키니 · 단호박   한우 등심 · 호주산 등심
          └ 규격  상품 · 중품 · 유기농     1++ · 1+ · 1
              └ 상품  (판매처가 파는 포장 단위. 예: 애호박 2입 500g)
```

- **품종이 판정의 단위다.** 판정은 품종 × 규격 조합마다 낸다.
- 품종을 나누는 규칙: 사용자가 서로 다른 평소가를 기대하면 다른 품종이다. 한우 등심과 호주산 등심은 가격대가 3배 이상 달라서 다른 품종이고, 1++와 1+는 같은 품종의 다른 규격이다.
- 품종마다 **기본 규격**이 하나 있다. 가장 흔히 팔리는 규격이다 (애호박은 "상품", 한우 등심은 "1+"). 품종 화면은 기본 규격으로 열리고, 다른 규격은 전환해서 본다.
- 우리 분류는 **원천 데이터의 분류와 독립된 자체 분류**다. 원천 코드는 우리 품종으로 다대일 연결된다.
  - KAMIS는 "호박"이 품목, "애호박"이 품종이라 우리 계층과 대체로 맞는다.
  - 하지만 삼겹살은 KAMIS 안에서도 `돼지-삼겹살(4304-27)`, `수입돼지-삼겹살(4402-27)`, `삼겹살(국산냉장)(514-00)`, `삼겹살(수입냉동)(514-01)`로 흩어져 있다. 이 코드들을 우리 품종으로 묶는 방법은 P4 어댑터에서 정한다.

## 2. 검색 흐름

```
검색어 ──별칭──▶ 품목에 일치 ──▶ 그 품목의 품종 목록 (자주 찾는 순) ──선택──▶ 품종 판정 화면
            └──▶ 품종에 일치 ─────────────────────────────────────────▶ 품종 판정 화면
```

- 예: "호박" → 품목 호박 → [애호박, 단호박, 쥬키니] 중 선택
- 예: "애호박" → 바로 애호박 판정 화면
- "자주 찾는 순"은 운영자가 정한 순서로 시작하고, 조회·검색 데이터가 쌓이면 그것으로 바꾼다.

### 결과가 없을 때

```
검색어 ──별칭 없음──▶ "아직 가격 정보가 없어요" 안내
                       ├─▶ 다른 사이트에서 보기 버튼 (네이버쇼핑, 쿠팡, 컬리 등의 검색 결과로 이동)
                       ├─▶ 비슷한 품종 추천 (있는 경우)
                       └─▶ 미등록 검색어로 기록
```

- 결과가 없는 경우는 두 가지다.
  - 우리 분류에 없는 품종 (예: "고수", "아보카도")
  - 분류에는 있지만 아직 시세가 없는 품종. 이때는 "가격 정보를 모으는 중이에요"로 안내를 구분한다.
- **다른 사이트로 가는 버튼은 해당 사이트의 검색 결과 페이지로 연결하는 링크일 뿐이다.** 상대 사이트의 데이터를 가져오거나 저장하지 않으므로 [data-sourcing-legal.md](../10-research/data-sourcing-legal.md)의 수집 리스크와 무관하다. 제휴 링크(쿠팡 파트너스 등)로 연결해 수익을 낼 수 있는지는 약관을 확인한 뒤 정한다.
- **미등록 검색어**는 사용자가 찾지만 우리에게 없는 품종의 목록이다. 많이 검색된 순서대로 품종 추가 우선순위를 정하는 데 쓴다.

## 3. 가격 개념의 관계

```
              ┌─ 소매 시세 (KAMIS, 축평원) ────┐
출처 ──관측──▶ │                               ├──▶ 평소가 ──비교──▶ 판정
              └─ 판매가 (참가격, 제보, 온라인) ──┘        ▲
                     │                                  │
                     └────── 판정 대상이 될 수 있음 ──────┘
도매 시세 ──▶ 상승·하락 예고 (소매 시세의 선행 신호)
가격 이슈 ──▶ 시세 변동의 설명
```

- **시세**와 **판매가**는 다른 개념이다. 시세는 여러 곳을 집계한 값이고, 판매가는 한 곳에서 관측한 값이다.
- 평소가는 주로 소매 시세로 만든다. 판매가로 보강할지는 P5에서 정한다.
- 판정 대상은 사용자가 입력한 가격, 특정 판매가, 오늘의 시세 모두 될 수 있다.
- **도매 시세**는 숫자를 상세 화면의 보조 정보로만 보여준다. 주된 용도는 "도매 가격이 2주째 올라서 소매 가격도 오를 수 있어요" 같은 예고 문구다.

### 행사 가격

- 행사가 붙은 판매가는 **1개당 실제 가격**으로 판정하고 행사 표시를 붙인다. 예: 애호박 1+1 3,960원 → 1개 1,980원, "1+1 기준".
- 평소가를 계산할 때는 행사 중인 판매가를 뺀다. 행사 때문에 평소가가 내려가지 않게 하려는 것이다.

### 평소가와 가격 이슈 기간

- 평소가는 "최근 1년 같은 달"과 "최근 몇 주의 중앙값"을 섞어 계산한다. 정확한 식은 P5에서 정한다.
- 가격 이슈 기간의 데이터도 평소가 계산에 그대로 넣는다. 이슈 때문에 실제로 평소 가격 수준이 바뀐 것일 수도 있기 때문이다.

### 갱신 지연

- KAMIS는 품절이면 전날 가격을 최대 5일까지 그대로 쓴다. 같은 값이 계속 이어지면 **갱신 지연**으로 보고, 화면에 표시하고 신뢰도를 낮춘다.

### 사용자에게 보이는 표현 (초안, P8에서 확정)

| 도메인 용어 | 화면 문구 | 설명 문구 예 |
|---|---|---|
| 소매 시세 | 전국 평균 시세 | "전국 22개 도시 마트·시장 평균" |
| 판매가 | 매장 가격 | "이마트 가양점, 10월 2일" |
| 평소가 | 평소 가격 | "최근 1년 같은 달 기준" |
| 도매 시세 | 도매 가격 | "마트에 들어가기 전 거래 가격. 보통 1~2주 뒤 소매가에 반영돼요" |

## 4. 단위 규칙

- 품종마다 **기준 단위**가 하나 있다.
  - 고기: 100g
  - 개수로 파는 채소: 1개 (애호박, 무, 양배추 등)
  - 가공식품: 가격표시제 실시요령 별표 2의 단위 ([content-and-taxonomy.md](../10-research/content-and-taxonomy.md) 4장)
- **고기는 100g 기준으로 계산하고, 예시 수량 200g·300g의 가격을 함께 보여준다.** 사용자가 실제 구매량으로 체감하게 하려는 것이다.
- 개수 단위 품종에는 **환산 기준**(1개 ≈ ○g)을 둔다. 중량으로 파는 상품을 개수 기준으로 판정할 때 쓰고, 환산을 거친 판정은 신뢰도를 한 단계 낮춘다.

## 5. 제보

MVP에 포함한다. 사용자는 본 가격을 입력하면 즉시 판정을 받고, 입력된 가격은 검증을 거쳐 다른 사용자에게 **매장 가격**으로 공개된다.

### 흐름

```
입력 ──▶ 즉시 판정 (입력한 사용자에게) ──▶ 이상 감지 ──┬─ 정상 ──▶ 공개
                                                      ├─ 의심 ──▶ 보류 (비슷한 제보가 더 오면 공개)
                                                      └─ 이상 ──▶ 제외 (통계에서 빠짐)
```

- **즉시 판정은 이상 감지와 관계없이 항상 보여준다.** 입력한 사람에게는 자기가 본 가격에 대한 답이 필요하다.
- 이상으로 감지되면 입력한 사용자에게 **안내 문구**를 보여준다.
  - 시세와 차이가 클 때: "평소보다 매우 비싸요. 단위(개/g)나 수량을 확인해 주세요"
  - 단위 착각이 의심될 때: "100g 가격이 아니라 한 팩 가격인가요?"
- 공개된 제보는 신뢰도가 공공 조사보다 낮게 표시된다. 같은 점포·품종에 일치하는 제보가 여러 건이면 신뢰도를 올린다.

### 이상 제보를 감지하는 신호

| 신호 | 예 |
|---|---|
| 시세와의 차이 | 소매 시세의 3배 이상, 또는 1/3 이하 |
| 단위 불일치 | 100g 가격으로 보기에 너무 크고, 한 팩 가격이면 정상 범위 |
| 반복 입력 | 같은 사용자가 짧은 시간에 같은 품종을 여러 번 입력 |
| 다른 제보와의 불일치 | 같은 점포·같은 날의 다른 제보들과 크게 다름 |
| 입력자 이력 | 과거 제보가 반복해서 이상으로 분류된 사용자 |

정확한 임계값과 점수 방식은 P5에서 정한다.

- 점포명이 포함된 제보를 공개할 때의 법적 문제는 출시 전 변호사 확인 목록에 있다 ([data-sourcing-legal.md](../10-research/data-sourcing-legal.md) 7장).

## 6. 가격 이슈

- 가격 이슈는 **기간**, **유형**, **영향받는 품목·품종**, **출처**를 갖는다.
- 유형: 기상(장마, 태풍, 폭염, 한파), 가축 질병(조류독감, 아프리카돼지열병, 구제역), 국제 정세(전쟁, 수출 제한, 환율), 수급(작황, 출하량)

### 감지 흐름

```
기상청 특보 ──────────┐
가축 질병 발생 현황 ───┼──▶ 이슈 신호 ──▶ 이슈 후보 ──운영자 확인──▶ 가격 이슈 (게시)
뉴스 키워드 (주기 수집) ┘                                └── 기각
운영자 직접 등록 ─────────────────────────────────────▶ 가격 이슈 (게시)
```

- **뉴스 키워드 수집**: 정해진 키워드("태풍", "조류독감", "배추값" 등)를 일정 주기로 검색하고, 키워드별 기사 수의 급증을 이슈 신호로 쓴다.
  - 저장 범위는 **기사 제목, 링크, 발행 시각, 키워드 빈도**로 한정한다. 기사 본문은 저장하지 않는다. 뉴스 기사도 저작권과 DB권의 보호 대상이기 때문이다.
  - 수집 경로(뉴스 검색 API, 언론사 RSS, 뉴스 빅데이터 서비스)와 각 경로의 약관은 P2에서 조사한다.
- **신호가 있어도 자동으로 게시하지 않는다.** 운영자가 실제 가격 변동과 연결되는지 확인하고 게시한다.
- 게시된 가격 이슈가 화면에 쓰이는 곳
  - 추이 차트 위에 기간 표시
  - 판정 화면의 설명 문구 ("8월 태풍 이후 호박류 상승")
  - 이슈 모아보기 콘텐츠

## 7. 제철

- 제철은 **품종 × 월**의 관계다. 한 품종은 여러 달이 제철일 수 있다.
- 월별 제철 콘텐츠는 제철 품종 목록에 각 품종의 현재 판정을 붙여 보여준다 ("제철이라 지금 평소보다 15% 싸요").

## 8. 시나리오 검증

| # | 시나리오 | 모델의 설명 |
|---|---|---|
| S1 | 한우 등심 1++ 13,000원/100g vs 호주산 등심 4,000원/100g | 다른 품종이므로 따로 판정 |
| S2 | 한우 등심 1++ vs 1+ | 같은 품종, 다른 규격. 규격별 판정. 기본 규격은 1+ |
| S3 | 애호박 1개 1,980원 vs 2입 500g 3,500원 | 기준 단위 1개, 환산 기준으로 비교, 신뢰도 하향 |
| S4 | "호박" 검색 | 별칭 → 품목 → 품종 목록에서 선택 |
| S5 | KAMIS 전국 평균 vs 이마트 가양점 가격 | 시세와 판매가로 구분 |
| S6 | 삼겹살 300g 팩 9,000원 | 100g당 3,000원으로 판정, 200g·300g 예시 표시 |
| S7 | 애호박 1+1 3,960원 | 1개 1,980원으로 판정, "1+1 기준" 표시, 평소가 계산에서 제외 |
| S8 | 품절로 KAMIS가 전날 가격을 반복 | 갱신 지연 표시, 신뢰도 하향 |
| S9 | 제보 가격이 시세의 3배 | 즉시 판정은 보여주고 안내 문구 표시. 이상 제보로 분류해 공개·통계에서 제외 |
| S10 | 태풍 기간 가격이 평소가에 섞임 | 그대로 반영. 같은 달 1년 기준과 최근 중앙값을 섞어 영향을 완화 |
| S11 | 한 사용자가 삼겹살 가격을 10분 동안 5번 입력 | 반복 입력 신호. 이상 또는 보류로 분류 |
| S12 | 삼겹살 한 팩 가격 15,000원을 100g 가격으로 입력 | 단위 불일치 신호. "한 팩 가격인가요?" 안내 |
| S13 | "태풍" 뉴스가 급증했지만 채소 시세는 그대로 | 이슈 후보로만 남고, 운영자가 기각하면 게시하지 않음 |
| S14 | 전쟁으로 수입 소고기가 오름 (자동 신호 없음) | 운영자가 가격 이슈를 직접 등록 |
| S15 | "고수" 검색 (우리 분류에 없음) | "아직 가격 정보가 없어요" + 다른 사이트 검색 버튼, 미등록 검색어로 기록 |
| S16 | 분류에는 있지만 시세가 아직 없는 품종 검색 | "가격 정보를 모으는 중이에요" + 다른 사이트 검색 버튼 + 제보 입력 유도 |
