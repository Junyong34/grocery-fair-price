### 참가격 포함 판매처

- 대형마트: **이마트, 농협하나로마트** (홈플러스·롯데마트 **없음**)
- SSM: 롯데슈퍼, GS더프레시
- 백화점: 현대, 신세계
- 편의점: CU, GS25, 세븐일레븐, 이마트24
- 전통시장 일부

### 주요 필드

- **참가격 가격**: 조사일, 업체ID, 상품ID, 가격, 할인여부, 할인 시작·종료일, 1+1 여부, 입력일시
- **참가격 판매점**: 업체명, 업태코드, 지역코드, 주소, 좌표
- **참가격 상품**: 상품명, 소분류코드, 용량, 단위, 제조사코드
- **KAMIS (data.go.kr판)**: 조사일, 소매/도매 구분, 부류, 품목, 품종, 등급, 시군구, 단위, 단위크기, 시장코드·명, 가격, kg환산가격, 등록일시
- **축평원**: 등급/원산지 구분, 평균·최고·최저가, 17개 시도별 가격, 단위(원/100g)

### 코드 예시

- KAMIS (부류-품목-품종): 애호박 `200-224-01`, 삼겹살 `500-4304-27`, 한우등심 `500-512-12`
- 축평원 축종: 소 4301, 돼지 4304, 수입 소 4401, 수입 돼지 4402
- 축평원 부위: 안심 21, 등심 22, 삼겹살 27, 갈비 28(돼지)/50(소), 목살 68

### 수산물

- 소매 시세는 **KAMIS 수산물 부류(600)** 가 가장 실용적이다 (26개 품목, 매일).
- 참가격에도 갈치, 고등어, 오징어, 조기, 연어, 새우가 있다.
- 위판장·도매시장 경락가는 산지 동향 참고용이다 (주기·라이선스 미확인).

### 보조 소스

- 통계청 KOSIS 소비자물가지수: 월 1회, 맥락 설명용 ("채소류 물가 전년 대비 +x%")
- 농정원 산지·도매·소매 통합 가격, 지자체 물가조사 API (data.go.kr 15109062)

## 2. 데이터가 UI에 주는 의미

- **"싼가 비싼가" 판정**은 KAMIS 평년·전년 가격으로 즉시 만들 수 있다. 직접 이력을 쌓기 전에도 서비스가 가능하다.
- **"업체별 추이"** 는 참가격만 가능하고, 주 단위·특정 업체로 한정된다. 화면 문구로 기대치를 조정한다 (예: "이마트·하나로마트·편의점 기준").
- **일별 시세 라인**(KAMIS)과 **업체별 점 데이터**(참가격)는 성격이 다르다. 차트에서 구분해 보여준다.
- 소고기는 등급별로 따로 판정해야 한다 (1++와 3등급을 섞으면 의미 없음).

## 3. 배치 설계

| 작업 | 주기 | 시점 | 메모 |
|---|---|---|---|
| KAMIS 일별 소매가 | 평일 1회 + 익일 재수집 | 14시 이후, 다음 날 오전 재수집 | 오후 조사분 지연 입력, 품절 시 전일가 대체(최대 5일) → 값이 바뀔 수 있음 |
| KAMIS 과거 백필 | 최초 1회 | - | 1년 단위로 분할 호출 |
| 축평원 소비자가격 | 매일 1회 | 미확인 (실호출로 확인) | 축종×부위×등급 조합 수를 1,000건/일 한도에 맞춰 계산 |
| 참가격 가격 | 주 1회 | 금~토 | 격주/매주 여부 먼저 확인. 할인·1+1 플래그 같이 저장 |
| 참가격 판매점·상품 마스터 | 월 1회 | - | 신규·폐점·상품 변경 동기화 |
| KOSIS 물가지수 | 월 1회 | 발표 후 | 보조 지표 |
| 판정·기준가 재계산 | 수집 직후 | - | 원천 데이터 → 정규화(100g당) → 기준가 → 판정 |

공통 원칙:
- **원천 응답을 그대로 보관**(raw)하고, 정규화된 데이터는 별도로 만든다. 단위 규칙이 바뀌면 다시 계산할 수 있어야 한다.
- 응답 필드가 대부분 문자열이다. 숫자 변환과 검증 단계를 둔다.
- 화면에 **출처 표기 문구**를 넣는다 (공공누리 1유형 의무).
- 운영 전에 운영계정 전환과 호출 한도 증설을 신청한다.
