# 04. 이미지 확보 전략

> 법률 자문이 아니다. 일부 공식 페이지는 접속이 막혀 **미확인**으로 남겼다.

## 1. 결론

- **쇼핑몰 상품 이미지는 저장해서 쓰지 않는다.** 저작권(연출 사진은 저작물로 인정될 수 있음)과 DB권, 약관 리스크가 겹친다.
- **품목 이미지는 AI 일러스트로 직접 만든다.** 비용이 작고, 스타일을 통일할 수 있다.
- **카테고리 아이콘은 오픈 라이선스 이모지로 시작한다.**
- 실사가 꼭 필요한 품목만 무료 스톡이나 직접 촬영으로 채운다.

## 2. 쇼핑몰 이미지 사용 리스크

- 제품만 충실히 찍은 사진은 창작성이 없다는 판례가 있다 (대법원 98다43366, 햄 광고 사진).
- 반면 구도·조명을 연출한 사진은 저작물로 인정될 수 있다 (대법원 2005도3130). 컬리처럼 연출 컷이 많은 몰은 위험하다.
- 저작권이 없어도 **대량 수집은 DB제작자 권리 침해**가 될 수 있다 (대법원 2021도1533).
- **핫링크**(원본 URL 임베드): 링크 자체는 복제가 아니라는 판례가 있지만(2012도13748), 침해물을 알고 영리적·계속적으로 링크하면 방조가 될 수 있다(2017도19025). 이미지 임베드 판례는 미확인. 회색지대이며 약관 위반 리스크는 남는다.
- **API 이미지**: 네이버 쇼핑 API는 저장·가공 금지. 쿠팡 파트너스 API는 데이터 복제·저장 금지. → 품목 이미지 DB로 쓸 수 없다.

## 3. 무료 · 공공 이미지 소스

| 소스 | 상업 이용 | 출처 표기 | 주의 |
|---|---|---|---|
| Pexels | 가능 | 불필요 | 스톡 재배포 금지 |
| Unsplash | 가능 | 불필요 (API 사용 시 작가 표기·핫링크 필요) | 한국 식재료 커버리지 낮음 |
| Wikimedia Commons | 파일별 | CC-BY는 표기 필요, SA는 동일조건 | 파일마다 라이선스 직접 확인 |
| 공공누리 0·1유형 | 가능 | 1유형은 필요 | 2·4유형은 상업 불가 |

| Pixabay | 미확인 | 미확인 | 접속 차단으로 확인 못 함 |

- 한국 식재료 커버리지: Commons에서 "perilla leaves" 698건, "aehobak" 26건.
- 농진청·aT·식약처의 범용 품목 이미지 DB는 찾지 못했다 (미확인).

## 4. AI 생성 이미지

### 비용 (1024×1024, 공식 가격표)

| 모델 | 1장 | 3,000장 |
|---|---|---|
| GPT Image 2 low | $0.006 | 약 $18 |
| GPT Image 2 medium | $0.053 | 약 $159 |
| GPT Image 2 high | $0.211 | 약 $633 |
| Imagen 4 Fast | $0.02 | 약 $60 |
| Imagen 4 | $0.04 | 약 $120 |

OpenAI는 입력 토큰 비용이 별도다. 일괄 생성 소요 시간은 rate limit에 따라 다르다 (미확인). 배치 스크립트로 돌리면 사람이 할 일은 **검수**가 대부분이다.

### 쟁점

- AI 단독 생성물은 저작권 보호를 받기 어렵다 (저작권법 제2조 제1호). 경쟁사가 가져가도 막기 어렵다.
- AI기본법 제31조(2026-01-22 시행)에 생성형 AI 결과물 표시 의무가 있다. 우리 사이트가 의무 대상인지는 미확인이므로, **"AI로 생성한 이미지" 표기를 기본으로 한다.**
- OpenAI 약관은 출력물 권리를 이용자에게 양도한다. Midjourney·Stability·Gemini 약관은 미확인.

### 스타일 통일

- 고정 프롬프트 템플릿: `{품목}, 흰 배경, 45° 탑뷰, 소프트 그림자, 플랫 일러스트`
- 모델·버전·크기 고정, 기준 이미지를 참조로 입력
- 깻잎, 애호박, 두부처럼 **한국 고유 식재료를 정확히 그리는지 시험 생성으로 먼저 검증**한다.

## 5. 아이콘 · 이모지

| 세트 | 라이선스 |
|---|---|
| Microsoft Fluent Emoji | MIT |
| Twemoji (그래픽) | CC-BY 4.0 |
| OpenMoji | CC BY-SA 4.0 |

한국 식재료(애호박, 두부, 깻잎)는 이모지에 거의 없다. 카테고리 대표 아이콘 정도로만 쓴다.

## 6. 권장 단계

1. **MVP**: 카테고리 아이콘(Fluent Emoji) + 상위 100~300개 품목 AI 일러스트 (약 $2~16). AI 생성 표기.
2. **보강**: 실사가 필요한 품목은 Pexels·공공누리 0/1유형·Commons CC-BY. **이미지마다 라이선스·출처 메타데이터를 DB에 저장한다.**
3. **확장**: 수천 개 품목 AI 일괄 생성. 노출이 많은 품목은 직접 촬영이나 디자이너 일러스트로 교체 (저작권 확보).
4. **상품(SKU) 이미지**: 저장하지 않는다. 장기적으로 제조사·몰과 피드 제휴로 확보한다.
