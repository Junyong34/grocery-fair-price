# KAMIS 자체 Open API 17종과 장볼날 시세

2026-11-17에 KAMIS 사용안내의 1~17번 상세 명세를 확인하고 17개 모두 직접 호출했다. 16개는 공개 예시 또는 발급 키로 데이터 응답을 확인했다. 2번만 날짜·규격·도소매 구분을 바꾼 요청이 모두 시간 초과됐다. 발급 키의 호출 한도, 전체 품종과 지역의 데이터 가용성, 운영 DB 적재 상태는 미확인이다. [KAMIS Open API 목록](https://www.kamis.or.kr/customer/reference/openapi_list.do)

**우선순위는 기존 시세로 김장·주간 콘텐츠를 만들고, 친환경 감자부터 새 시세 화면을 검증하는 것이다.** 자체 Open API에서 지금 수집 중인 소매 시세와 다른 범위는 친환경 이력(5·11·12·13번)과 도매(16번)다. 두 범위 모두 기존 KAMIS 공공데이터포털 API에 해당 구분이 있다. 5·11번의 구 친환경 쌀, 12·13번의 신 친환경 감자, 16번의 중도매 배추 표본이 기존 API와 일치했다. 공공데이터포털에서 확보할 수 없는 새로운 가격 관측값은 이번 조사로 확정된 것이 없다.

### 자체 API에서 추가로 얻을 수 있는 값

- **KAMIS가 계산한 비교값**은 별도 활용 가치가 있다. 1번 명세에 평년이 있고, 7·16·17번 공개 응답에도 평년이 있었다. 3·4번은 월·연 단위 집계와 변동 통계를 명세에 제공한다. `perDay`의 관측값만으로 KAMIS와 동일한 평년·집계를 재현할 수 있는지는 산식과 표본을 확인해야 한다. 장볼날 상세에 붙인다면 ‘KAMIS 평년’으로 출처를 표시한다. 장볼날 평소가는 최근 26주 시세 수준과 3년 계절비율을 쓰는 별도 값이다. [평소가 계산](../../30-data/judgment.md)
- **15번 코드표**는 가격 구분별 조사 단위·수량·등급을 함께 준다. 기존 코드표와 응답을 대조해 새 원천 코드와 단위를 확인하는 데 쓸 수 있다. 가격 관측값이 확인된 규격만 시세에 연결한다. [15번 공개 응답](15-product-grades.md)
