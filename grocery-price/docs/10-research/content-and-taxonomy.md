## 2. 제철 · 영양 데이터

- **농정원 제철 농식품 정보** (파일, 51건): 시즌월, 제목, 설명, 칼로리, 영양, 요리, 레시피. 2026-09-21 수정. 상업 이용 가능.
- **농진청 이달의 음식**: 월별 제철 농산물 기반 레시피.
- **해수부 이달의 수산물**: 공공데이터셋 없음 (미확인). 보도자료를 직접 정리해야 할 가능성이 높다. 월 1건이라 수작업으로 충분하다.
- **식약처 식품영양성분 DB API**: 상업 이용 가능.
- **농진청 국가표준식품성분표**: 공공누리 **2유형 (상업 이용 금지)** → 사용하지 않는다.

## 3. 카테고리 분류 참고

- **KAMIS**: 부류(100 식량작물 ~ 600 수산물) > 품목 > 품종 > 등급, 4단계 코드.
- **참가격 분류**: 곡물가공품, 정육·난류, 수산가공품, 낙농·축산가공품, 조미료·장류·식용유, 채소, 과자·빙과류, 차·음료·주류, 생선류, 기타 가공식품, 곡물.
- 통계청 물가 품목 분류, GS1 KAN 분류, 쿠팡·컬리·이마트몰 카테고리: 미확인.

설계 방향 ([product-concept.md](../00-overview/product-concept.md) 6장):
- 사용자용 분류는 장보기 동선에 맞춰 자체 정의한다 (채소 / 과일 / 정육·계란 / 수산 / 두부·면·가공 / 양념·장류 / 생필품).
- 원천 코드(KAMIS, 참가격 ID)는 매핑 테이블로 연결한다.

## 4. 단위가격 표시제 (정규화 기준)

근거: **가격표시제 실시요령** (산업통상자원부고시 제2025-51호, 2025-04-07 시행)

- 대상: 대규모·준대규모 점포 안의 소매점, 연 거래액 10조원 초과 온라인몰
- 10진 단위(g, kg, ml, l, 매, m)를 쓴다. 1원 단위로 표시하고 1원 미만은 반올림한다.
- 표시 제외: 30g/30ml 이하, 500원 이하, 복합 포장, 단일 규격 상품

| 표시 단위 | 품목 예시 |
|---|---|
| **100g** | 농·수·축산 신선식품 전체, 두부, 면류, 밀가루, 즉석밥, 김치, 어묵, 고추장, 된장, 고춧가루, 설탕 |
| 10g | 햄, 소시지, 베이컨, 치즈, 참치캔, 조미김, 젓갈, 과자, 빵 |
| 100ml | 우유, 식용유, 간장, 주류, 생수, 음료 |
| 10ml | 참기름, 식초, 액젓, 발효유, 아이스크림 |
| 기타 | 화장지 10m, 미용티슈 10매, 기저귀·생리대 1개 |

- 계란은 별도 항목이 없어서 축산물 100g에 해당하는 것으로 보인다. 다만 소비자는 "1구당"이 익숙하므로 **보조 단위로 개당 가격을 같이 보여주는 것**을 검토한다.
- 애호박처럼 **개 단위로 파는 신선식품**은 개당 평균 중량 환산 규칙이 필요하다 (KAMIS kg 환산가격 활용).

## 5. 유사 서비스 UI 사례

- **trolley.co.uk (영국)**
  - 판매점별 가격 + "£0.07 per 100g" 단위가격
  - "Today's Price": **Lowest / Usually / Highest** 3점 비교 + 현재가
  - 딜 목록에 "42% Cheaper" 평소가 대비 배지
  - 월간 Grocery Price Index 공개 (47,910개 상품), 가격 데이터 API 판매 → 수익 모델 참고
- **hotprices.org (호주) / heisse-preise.io (오스트리아)**: 가격 변동 목록, 장바구니 추적
- **참가격 (국내)**: 장바구니 가격 비교, 업체별·지역별·주차별 가격 동향
- 신호등 방식을 쓰는 실제 사례와 국내 민간 장보기 앱은 미확인.

→ **신호등(판정) + 3점 비교(근거) + 평소 대비 %(배지)** 조합이 우리 메인 UI의 출발점이다.
